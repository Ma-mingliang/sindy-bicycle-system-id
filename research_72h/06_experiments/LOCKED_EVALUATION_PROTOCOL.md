## 1. 主指标

### PrimaryLongHorizonScore

```
PrimaryLongHorizonScore = mean(NMAE_H100, NMAE_H200, NMAE_H500)
```

**理由**:
- H=100, 200, 500 覆盖中长步程到长步程
- 是 v9 的主要弱点区域
- 与 MPC 规划窗口相关

### v9 基线

```
v9 PrimaryLongHorizonScore = mean(0.5064, 0.4737, 0.5529) = 0.5110
```

## 2. 辅助指标

### 2.1 全 Horizon NMAE

| Horizon | 用途 |
|---------|------|
| H=1 | 单步精度 |
| H=10 | 短期精度 |
| H=50 | 中期精度 |
| H=100 | 长期精度（主要） |
| H=200 | 长期精度（主要） |
| H=500 | 超长期精度（主要） |
| H=1000 | 极限测试（可选） |

### 2.2 Per-State NMAE

每个状态单独报告，用于识别特定弱点：
- e_y: 横向位置
- e_psi: 航向角
- v: 速度
- theta: 横滚角
- theta_dot: 横滚角速度
- delta: 转向角
- delta_dot: 转角速度

### 2.3 存活率

物理存活率：各状态在物理限制内的比例

### 2.4 发散率

数值发散率：出现 NaN/Inf 或 |state| > 100 的比例

## 3. "巨大提升" 标准

必须同时满足：

1. **主指标下降 ≥ 35%**:
   - PrimaryLongHorizonScore ≤ 0.5110 * 0.65 = 0.3322

2. **H=500 NMAE 下降 ≥ 30%**:
   - H=500 NMAE ≤ 0.5529 * 0.70 = 0.3870

3. **至少 5 个配对 seed**:
   - 使用 seed 42, 43, 44, 45, 46

4. **至少 80% seed 改善方向一致**:
   - 5 个 seed 中至少 4 个改善

5. **配对 bootstrap 改善概率 ≥ 95%**:
   - 或合理 95% 区间支持改善

6. **H=1 和 H=10 不退化 > 5%**:
   - H=1 NMAE ≤ 0.0051 * 1.05 = 0.0054
   - H=10 NMAE ≤ 0.0628 * 1.05 = 0.0660

7. **关键状态不恶化**:
   - e_y, e_psi 不因平均值掩盖而恶化

8. **发散率不增加**:
   - 发散率 ≤ v9 发散率

9. **OOD 不弱于 v9**:
   - OOD 测试集表现不显著退化

10. **结果独立复现一次**:
    - 至少两次独立训练得到一致结果

11. **无测试集调参和数据泄漏**:
    - 验证集用于选模型
    - 测试集仅用于最终评估

## 4. 数据划分

### 4.1 划分方式

按 episode 75/25 划分：
- 训练集: 75% 的 episode
- 测试集: 25% 的 episode

### 4.2 归一化

- 所有归一化统计量只来自训练集
- 测试集不参与统计量计算

### 4.3 验证集

- 从训练集中划分 10% 作为验证集
- 用于早停和模型选择
- 测试集不用于调参

---

## 5. 评估流程

### 5.1 训练阶段

1. 在训练集上训练模型
2. 在验证集上监控性能
3. 使用早停防止过拟合
4. 保存最佳模型

### 5.2 评估阶段

1. 加载最佳模型
2. 在测试集上评估所有 horizon
3. 计算主指标和辅助指标
4. 记录存活率和发散率

### 5.3 统计分析

1. 多 seed 评估（至少 5 个 seed）
2. 计算均值、标准差、中位数
3. 配对比较（与 v9 对比）
4. Bootstrap 置信区间
5. 效应量（Cohen's d）
