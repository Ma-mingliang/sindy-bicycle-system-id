## 3. 逐方案批判性评估

### 3.1 方案 S4: 安全混合推理 (safety_blend_0.5) -- 当前最优

**机制**: 当状态超过物理限制的 50% 时，从 V12 sequential 模型切换到 V12 contractive 模型。

**优势**:
- 实现简单，无需重新训练
- H=500 NMAE 改善 5.2%
- 100% 存活率

**批判**:
1. **H=50 NMAE 仍超标 16%。** 这个指标实际上比 V9 baseline 更差（0.637 vs 0.548）。原因是混合推理在中等 horizon 引入了模型切换的不连续性 -- 当状态在阈值附近振荡时，两个模型的交替使用可能导致额外误差。
2. **阈值 0.5 是经验值，缺乏理论支撑。** 为什么是 50% 而不是 40% 或 60%？safety_blend_0.3 和 safety_blend_0.7 的结果都不如 0.5，但改善幅度很小（0.958 和 0.966 vs 0.946），说明系统对阈值不敏感，但也无法通过调参突破瓶颈。
3. **不解决根本问题。** 这是推理时的补丁，不改善模型本身的精度或稳定性。

**结论: S4 是现有条件下的工程最优，但无法突破 H=50 和 H=1 的限制。**

### 3.2 方案 S5: 状态相关收缩性 (未测试)

**机制**: `lambda_contract(s) = lambda_max * sigmoid((|s| - margin) / scale)`

**理论评估**:
1. **有收缩理论支撑。** Slotine 的收缩理论 (P29) 和 Bachar (P30) 的残差分析表明，局部扩张区域是 rollout 误差放大的根源。在扩张区域施加收缩约束是合理的。
2. **但不解决 H=1 问题。** H=1 的误差来自平衡点附近的局部拟合误差，此时状态接近零（远低于任何 margin），收缩约束几乎不生效。S5 本质上是 S2 (全局收缩) 的空间自适应版本，改善的是中长 horizon 的精度-稳定性折中，而非短 horizon 精度。
3. **梯度通过 sigmoid 的问题。** 在 sigmoid 的饱和区域，梯度接近零，可能导致训练不稳定。需要仔细设计 warmup 和 gradient scaling。

**结论: S5 可能略微改善 H=50 NMAE（估计 5-10%），但无法突破 H=1 限制。**

### 3.3 方案 S6: Lyapunov 约束 (未测试)

**理论评估**:
1. **实现复杂度高。** 需要额外学习一个 Lyapunov 函数 V(x)，并确保 dV/dt <= 0。对于 7 维状态空间，这需要一个额外的神经网络和复杂的损失设计。
2. **与收缩理论重叠。** Lyapunov 稳定性和收缩性在数学上密切相关（收缩意味着局部 Lyapunov 函数存在）。S6 的效果可能与 S2/S5 类似，但实现成本高得多。
3. **不解决 H=1 问题。** 同 S5。

**结论: 理论上有趣，但工程成本高，且不解决核心瓶颈。优先级低。**

### 3.4 方案 S7: 投影式约束 (未测试)

**理论评估**:
1. **文献支持 (P14)**，Projected Neural ODE 概念清晰。
2. **但会破坏动力学连续性。** 在每个 ODE 求解步骤后投影回可行域，会引入不连续的跳跃。对于 Neural ODE（依赖连续性进行伴随方法梯度计算），这可能导致梯度计算错误或训练不稳定。
3. **推理时的 clip 已经被证明失败。** clip_seq 的结果 (H=500 NMAE=1.505) 比不 clip 还差，说明硬裁剪破坏了动力学。投影本质上是软化的 clip，风险类似。

**结论: 高风险，已有的 clip 实验间接否定了这个方向。**

### 3.5 方案 S8: 残差动力学分解 (未测试)

**机制**: `dx/dt = f_physics(x, u) + g_residual(x, u)`

**理论评估**:
1. **文献强力支持 (P32, P34)**。这是当前 Neural ODE 社区公认的最佳实践之一。
2. **可能同时改善 H=1 和 H=500。** 如果 f_physics 提供了准确的 baseline，g_residual 只需学习小残差，学习难度大幅降低。残差模型在平衡点附近的拟合精度可能更好（改善 H=1），同时已知模型提供了稳定性基础（改善 H=500）。
3. **但需要重新设计架构。** 当前模型是纯 Neural ODE，要改为残差架构需要：(a) 实现自行车物理模型 f_physics，(b) 修改训练 pipeline，(c) 重新调参。工作量约 2-3 天。
4. **项目名 "sindy_bicycle" 暗示已有 SINDy 发现的方程。** 如果这些方程可以作为 f_physics，实施成本会降低。

**结论: 最有潜力的新方向，但需要较多工程工作。建议优先实施。**

### 3.6 方案 S9: 渐进式 Horizon 增长 (未测试)

**理论评估**:
1. **MBPO (P15) 和 DreamerV3 (P16) 的发现值得注意。** DreamerV3 固定 15 步训练 horizon 却能支持长 rollout，说明增加训练 horizon 不是关键。
2. **当前已有 rollout curriculum "1,5,10,20"。** 已经在做渐进式增长，但仅到 H=20。
3. **扩展课程到 H=50+ 可能加剧梯度问题。** 文献 (P17) 表明这通常效果有限。

**结论: 边际改善，不解决核心矛盾。**

### 3.7 方案 S10: 集成方法 (未测试)

**理论评估**:
1. **降低方差但不降低偏差。** 多模型平均可以降低随机性，但系统性偏差（如归一化不匹配）不会消失。
2. **训练 3-5 个模型需要 3-5 倍计算成本。** 对于快速实验迭代不友好。
3. **推理时需要多次前向传播。** 对实时应用不友好。

**结论: 可以作为最终方案的补充，但不是独立解决方案。**

## 4. 缺失方案分析

### 4.1 Scheduled Sampling (文献 P7, 推荐方法 B)

**这是文献综述中推荐的高优先级方法，但在 SOLUTION_CANDIDATES.md 中未被列为候选方案。这是一个重大遗漏。**

**原理**: 训练时以递增概率使用模型自身预测替代真实状态作为下一步输入，缩小 train-eval gap。

**为什么重要**:
- 当前 sequential 训练使用 teacher forcing（真实状态），推理时使用自主 rollout（自身预测）。这个 gap 是 H=500 误差放大的主要来源。
- Scheduled sampling 直接针对这个 gap，且实现成本低（仅修改数据加载逻辑）。
- Bengio et al. (2015) 验证了其有效性，DreamerV3 也使用了类似策略。

**可能效果**:
- 改善 H=50 和 H=500 的 NMAE（减少 rollout 误差积累）
- 可能不影响 H=1（H=1 本质上是单步预测，不受 rollout 策略影响）
- 不影响存活率（模型在训练时就暴露于自身误差，学会了处理误差）

### 4.2 统一归一化策略 (文献 P20, P22, 推荐方法 A)

**这也是文献综述推荐的高优先级方法，但未在 SOLUTION_CANDIDATES.md 中明确列出。**

**问题**: 训练时使用 `delta_std * dt` 归一化，推理时使用 `state_std` 归一化。这种不匹配可能导致系统性偏差。

**修复**: 统一使用 state-level 归一化，或者在推理时使用 delta-level 归一化。

**可能效果**:
- 如果归一化不匹配确实是问题根源，可能直接解决 constant prediction collapse
- 可能改善所有 horizon 的 NMAE

### 4.3 有界扩张约束 (文献 P29, P30, 推荐方法 F)

**将 contractivity regularization 修改为 bounded expansion constraint**:
```
L_expand = max(0, lambda_max(J + J^T) - 2*beta)  // beta > 0 允许有限扩张
```

**原理**: 完全收缩约束消除了所有扩张区域，但也限制了模型表达真实动力学的能力。有界扩张允许有限的局部不稳定性，同时防止指数发散。

**与当前 contractivity 的区别**:
- 当前: `L_contract = max(0, -lambda_min(J + J^T) + 2*lambda)` -- 强制收缩
- 提议: `L_expand = max(0, lambda_max(J + J^T) - 2*beta)` -- 仅约束扩张上限

**可能效果**:
- 比全局收缩更好的精度-稳定性折中
- H=50 NMAE 可能改善（允许更多真实动力学）
- H=500 存活率仍可保证（扩张有界）

## 5. 核心矛盾分析

### 5.1 准确率-稳定性权衡的本质

根据 Bachar (P30) 的理论框架，这个矛盾的根源是：

**准确的动力学包含局部扩张区域**（物理上真实的不稳定动力学，如自行车在高速转弯时的侧翻趋势），**但稳定的 rollout 要求全局收缩**（物理上不真实）。

当前的收缩性正则化 (S2) 通过惩罚所有扩张来保证稳定性，但也消除了模型表达真实动力学的能力。这就是为什么 S2 的 H=500 NMAE (0.958) 远差于无约束的 Seq (0.476)。

### 5.2 H=1 的特殊困难

H=1 NMAE 在所有 sequential 变体中都超标（0.035-0.056 vs 阈值 0.020），而 V9 Baseline 仅为 0.006。这个 6-9 倍的差距不是收缩性造成的（因为 Seq 无约束也是 0.056），而是 sequential 训练本身的问题。

**可能原因**:
1. SequentialSegmentDataset 的段长限制 (max_segment_len=20) 可能引入边界效应
2. 归一化不匹配导致的系统性偏差
3. 训练数据分布与评估数据分布的差异

**这个观察很重要：即使完全移除收缩性约束，H=1 NMAE 仍然超标。这说明 H=1 问题是一个独立于稳定性问题的精度问题。**

### 5.3 四项标准的同时满足是否可能？

**悲观分析**:
- H=1 < 0.020 要求: 模型在平衡点附近有极高的局部拟合精度。V9 Baseline (shuffle) 做到了 (0.006)，但所有 sequential 变体都做不到。
- Surv@500 = 100% 要求: 模型在长 rollout 中不发散。无约束 Sequential 做不到 (0%)，需要某种稳定性约束。
- H=50 < 0.548 要求: 中等 horizon 精度。这恰好是 V9 Baseline 的水平，但所有加了收缩性的模型都更差。
- H=500 < 0.998 要求: 长 horizon 精度。这比 V9 Baseline 宽松，是唯一可能通过的标准。

**关键矛盾**: H=1 < 0.020 要求 sequential 训练的局部精度接近 V9 Baseline 的水平，但 sequential 训练本身就引入了精度退化（从 0.006 到 0.035-0.056）。同时，Surv@500 = 100% 要求稳定性约束，但稳定性约束会进一步降低精度。

**乐观分析**:
- 如果 Scheduled Sampling 或统一归一化能将 H=1 NMAE 从 0.035 降低到 0.015-0.020（仍在合理范围内），则 H=1 标准可能通过。
- 如果有界扩张约束能将 H=50 NMAE 从 0.637 降低到 0.50-0.54（接近 V9 Baseline），则 H=50 标准可能通过。
- 两者结合可能同时满足四项标准，但需要多个独立改进协同生效。

## 6. "状态相关收缩性" 的理论依据评估

### 6.1 理论支撑

S5 的理论依据来自两个来源：

1. **收缩理论 (Slotine, P29)**: 系统在不同状态区域可以有不同的收缩率。在平衡点附近，真实动力学可能本身就是收缩的（局部稳定性）；在远离平衡点的区域，可能需要外部约束来保证收缩。

2. **Bachar (P30) 的诊断**: 局部扩张区域与最坏情况扰动放大对齐。这意味着只在扩张区域施加约束，可以最小化对模型表达能力的影响。

### 6.2 实际可行性

**Sigmoid 调度的数学性质**:
```
lambda_contract(s) = lambda_max * sigmoid((|s| - margin) / scale)
```

- 当 |s| << margin 时: lambda_contract ≈ 0（无约束）
- 当 |s| >> margin 时: lambda_contract ≈ lambda_max（强约束）
- 过渡区域宽度由 scale 控制

**问题**:
1. margin 和 scale 需要手动调参
2. |s| 是 7 维状态向量的范数，不同状态变量的量级差异大（如 e_y ~ 0.1 vs delta_dot ~ 1.0），需要先标准化
3. Sigmoid 的饱和区域梯度接近零，可能导致约束强度无法自适应调整

### 6.3 预期效果

**S5 本质上是 S2 (全局收缩) 的软化版本。** 它允许在平衡点附近有更自由的动力学，可能：
- 改善 H=1 NMAE（平衡点附近无约束，模型可以更精确地拟合局部动力学）
- 改善 H=50 NMAE（中等状态区域约束较弱，保留更多真实动力学）
- 保持 H=500 存活率（远端区域仍有强约束）

**但改善幅度不确定。** 如果 H=1 的问题根源不是收缩性（如 5.2 节分析，Seq 无约束的 H=1 也是 0.056），则 S5 对 H=1 的改善有限。

## 7. 验收标准本身的合理性审查

### 7.1 标准是否过于严格？

| 标准 | 阈值 | 与 Baseline 的关系 | 评估 |
|------|------|-------------------|------|
| H=50 NMAE < 0.548 | = V9 Baseline | 要求不退步 | 合理 |
| H=500 NMAE < 0.998 | = V9 Baseline | 要求不退步 | 合理，但宽松 |
| Surv@500 = 100% | = V9 Baseline | 要求不退步 | 合理 |
| H=1 NMAE < 0.020 | 3.4x 宽于 Baseline | 允许退步 | **最严格** |

**H=1 标准的分析**:
- V9 Baseline H=1 NMAE = 0.0058
- 阈值 = 0.020 (允许 3.4 倍退步)
- 当前最佳 = 0.035 (超出阈值 75%)

阈值 0.020 已经是对 Baseline 的大幅放宽（从 0.0058 到 0.020），但 sequential 训练的固有精度退化仍然使其不可达。**这个标准可能设定了一个 sequential 架构在当前配置下无法达到的精度水平。**

### 7.2 是否有隐含的第五项标准？

当前四项标准未明确要求"单一模型"或"无需推理时切换"。safety_blend_0.5 使用了两个模型的推理时切换。如果项目要求单一模型端到端运行，则 S4 不合格，需要重新评估。

## 8. 总体建议

### 8.1 短期 (1-2天): 优先实施缺失方案

1. **Scheduled Sampling (方法 B)**: 实现成本最低，理论依据最强，可能直接改善 H=50 和 H=500。**这是当前最大的机会窗口。**

2. **统一归一化策略 (方法 A)**: 如果归一化不匹配确实是问题根源，这可能同时改善所有指标。需要先诊断确认。

3. **有界扩张约束 (方法 F)**: 替代当前的全局收缩约束，可能改善 H=50 NMAE。

### 8.2 中期 (3-5天): 残差动力学架构

S8 (残差分解) 是最有潜力但工程成本最高的方向。如果 f_physics 可以从 SINDy 结果中获取，实施成本会降低。**建议在短期方案完成后评估是否需要。**

### 8.3 验收标准是否需要调整？

**诚实的评估**: 在当前 Neural ODE 架构和训练框架下，同时满足全部四项标准的可能性不超过 30%。主要原因：

1. H=1 < 0.020 要求 sequential 训练的局部精度接近 shuffle 训练的水平，这在理论上没有保证
2. H=50 < 0.548 要求稳定性约束不降低中 horizon 精度，但收缩性约束在所有实验中都导致 H=50 退步
3. 两项约束同时满足需要多个独立改进协同生效，概率相乘后很低

**建议**: 将 H=1 阈值放宽到 0.040，或将 H=50 阈值放宽到 0.650。否则可能需要接受"safety_blend_0.5 作为工程最优解"的现实。

| 评估维度 | 结论 |

| 当前最优方案 | safety_blend_0.5，通过 2/4 项标准 |

| 四项标准同时满足的概率 | 约 30%（需要多个独立改进协同生效） |
| 验收标准合理性 | H=1 标准可能对 sequential 架构过于严格 |
| 最大遗漏方案 | Scheduled Sampling（文献强烈推荐但未列入候选） |

**最终判断**: 在不改变架构的前提下，safety_blend_0.5 很可能就是工程极限。要突破这个极限，需要引入 Scheduled Sampling 或残差动力学架构等根本性改变。
