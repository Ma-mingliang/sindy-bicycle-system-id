## 1. 模式定义

```python
# 每步使用真实状态作为输入，测试单步预测精度
for step in range(n_steps):
    tau = tau_func(step, s_real)
    s_pred = model(s_real, tau)  # 使用真实状态作为输入
    s_real = real_step(s_real, tau)
```

**用途**: 评估模型的单步预测精度，无误差累积。

---

## 3. Mode A 的特点

1. **无误差累积**: 每步使用真实状态，误差不会传播
2. **测试纯单步精度**: 不受控制器和长期预测影响
3. **基准测试**: 最基本的模型精度评估

### 3.1 与其他模式的关系

| 模式 | 输入来源 | 误差累积 | 测试目标 |
|------|----------|----------|----------|
| Mode A | 真实状态 | 无 | 单步精度 |
| Mode B | 固定动作 | 有 | 开环预测 |
| Mode C | tau来自真实 | 有 | 混合预测 |
| Mode D | tau来自模型 | 有 | 闭环控制 |

---

## 4. 关键发现

1. **GP标准模型单步完美**: 归一化后 MAE = 0，是最精确的单步预测器
2. **SINDy单步精确**: 0.002 rad MAE，适合快速原型
3. **线性化模型有系统误差**: 0.018 rad MAE，来自线性化近似
4. **GP-B4快速收敛**: 10步后误差降至0，说明近似误差主要在初始阶段
5. **Mode A不能预测长期表现**: 单步精确不等于长期稳定

---
