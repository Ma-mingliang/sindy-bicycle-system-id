### 1.2 核心矛盾一: BUG-002 归一化不匹配的定性分歧

**分歧本质**: Agent B/C 将 V9 多步 rollout 中的归一化混合视为 CRITICAL bug；Agent A/G 将其降级为 INFORMATIONAL/LOW，认为 V9 内部一致。

**深入分析**:

Agent G 的论点:
- V9 predict() 单步推理的归一化链数学上自洽
- V12 也内部一致，只是用了不同的归一化方案
- 结论: 这是设计选择差异，非 bug

Agent B/C 的论点:
- V9 rollout 步: `s_next_norm = s_norm + dsdt * dt = s_norm + delta/delta_std`
- V9 target: `s_next_norm = s_norm + delta/state_std`
- 两者不等价: `delta/delta_std != delta/state_std`（除非 `delta_std == state_std`）
- 误差每步累积，20步 rollout 后灾难性放大

**仲裁结论**: **Agent B/C 正确，Agent G 的降级存在逻辑错误。**

Agent G 的关键错误在于: 将 predict() 的单步正确性等同于训练 rollout 的内部一致性。predict() 正确是因为反归一化链 `dsdt_norm * delta_std * dt` 完美抵消了训练归一化。但训练中的多步 rollout 使用了不同的计算路径 `s_cur + dsdt * dt`，这个路径不经过反归一化，因此暴露了 delta_std 与 state_std 的不匹配。

具体证据: V9 rollout 中 `s_cur` 是 `state/state_std`，`dsdt * dt` 是 `delta/delta_std`。相加后得到 `state/state_std + delta/delta_std`，而 target 是 `state/state_std + delta/state_std`。对自行车模型的 e_y 分量，`delta_std ~ 0.01m` 而 `state_std ~ 0.5m`，比值约 50 倍——这意味着每步 rollout 增量被放大 50 倍。

**因此: BUG-002 维持 CRITICAL 评级。Agent G 的降级不成立。**

### 1.3 核心矛盾二: V9 基线常数预测假设

**分歧本质**: Agent A/D 认为 V9 基线接近常数预测（H=500 NMAE=0.998 + 100% 存活）；Agent G 否定此假设（V9 的 NMAE 单调递增，非常数）。

**深入分析**:

Agent G 的数据:
- V9 基线 per-state NMAE 在 H=500 时: e_y=1.281, e_psi=1.719, v=0.682, theta=0.315, theta_dot=0.870, delta=0.415, delta_dot=1.706
- 所有状态的 NMAE 从 H=1 到 H=500 单调递增
- 对比: v12_extended_rollout 在 H>=50 后 NMAE 恒定为 0.3666（真正的常数预测）

**仲裁结论**: **Agent G 的数据观察正确，但结论过度外推。**

Agent G 正确地指出 V9 的 NMAE 不是字面意义上的"常数预测"（模型输出不完全恒定）。但 Agent D 的因果分析更精确: V9 的多步损失因 shuffle 被破坏后，模型只能依赖单步损失，学习到的是一种"近恒等"映射（预测变化极小）。这不等于输出恒定值，而是输出变化极小的预测。

两种描述都捕获了同一个现象的不同侧面:
- Agent G: "V9 有学习到有意义的动力学（NMAE 单调递增）"
- Agent D: "V9 的多步损失无效，模型退化为近单步学习器"

实际上两者可以共存: 单步损失确实让模型学到了一些局部动力学（所以 NMAE 不是常数），但多步动力学从未被有效训练（所以 H=500 NMAE 接近 1.0）。100% 存活率是因为单步预测的误差在每步都很小，但累积 500 步后误差恰好未超出宽松的物理限制。

**修正判定**: V9 基线不是"完全的常数预测"，而是"单步有效、多步无效的近恒等映射"。Agent A 的 85% 置信度应调整为: 常数预测假设**部分成立**（多步动力学确实未学习），但不完全准确（单步预测有效）。

## 2. 遗漏识别

### 2.1 重大遗漏: Scheduled Sampling 未被列为方案候选

Agent F 的文献检索（34 篇论文）强烈推荐 Scheduled Sampling（Bengio 2015）作为高优先级方法，但 Agent H 的方案审计指出此方法**未出现在 SOLUTION_CANDIDATES.md 中**。

这是一个关键遗漏，因为:
1. Scheduled Sampling 直接针对 train-eval gap（训练用 teacher forcing，推理用自主 rollout）
2. 实现成本低（仅修改数据加载逻辑）
3. 可能同时改善 H=50 和 H=500 的 NMAE
4. 有 MBPO (Janner 2020) 和 DreamerV3 (Hafner 2023) 的实践验证

### 2.2 评估方法论遗漏

Agent E 识别了多个评估缺陷，但其他代理未充分整合这些发现:

1. **失败段 NMAE 计算窗口偏差**: 早期崩溃的段基于更少步数计算 NMAE，与完整 500 步的段被等权平均。这导致报告的 NMAE 可能系统性偏低。
2. **NMAE 跨 horizon 比较无意义**: H=1 的 NMAE=0.006 和 H=500 的 NMAE=0.998 不可直接比较，但验收标准将它们放在同一框架下。
3. **"条件 NMAE"未被标注**: 所有报告的 NMAE 实际是"仅存活段的条件 NMAE"，而非全样本 NMAE。

### 2.3 V12_extended_rollout 的常数预测未被充分关注

v12_extended_rollout 配置（训练到 H=100，400 epochs）的结果显示:
- H=50 到 H=500 的 NMAE 完全恒定为 0.3666
- per-state NMAE 也完全相同
- 这是**真正的常数预测坍缩**的直接证据

Agent G 正确识别了这一点，但其他代理（尤其是 A/D）未将其与 V9 基线的行为进行对比分析。v12_extended_rollout 的失败恰恰证明了: 扩展训练 horizon 到 H=100+ 会导致模型坍缩到常数预测，这是 Neural ODE 训练中的已知陷阱。

### 2.4 统计显著性不足未被量化

Agent E 指出 5 段样本量不足，但未提供具体的功效分析。基于 Agent E 的数据:
- 生存率 5/5 时 95% CI 下界仅约 45%
- NMAE 的 95% CI 半宽约 1.24 倍标准差
- 这意味着: safety_blend_0.5 的 H=500 NMAE=0.946 和 V9 baseline 的 0.998 在统计上**可能不可区分**

### 2.5 MLP 架构容量限制未被深入讨论

Agent A 简要提到 MLP 架构可能缺乏表示能力（128-hidden, 2-depth, tanh），但未有代理深入分析: 7 维自行车动力学是否需要更大的网络或不同的架构（如 ResNet、attention）。

## 4. 最终建议

### 4.1 根因修复优先级（基于综合审计）

| 优先级 | 修复项 | 置信度 | 预期影响 | 工作量 |
|--------|--------|--------|----------|--------|
| P0 | 修复 shuffle + 归一化（采用 V12 方案） | 98% | 基础修复，必须完成 | 已完成 |
| P1 | 实施 Scheduled Sampling | 85% | 可能改善 H=50/500 NMAE | 1-2 天 |
| P2 | 有界扩张约束替代全局收缩 | 80% | 改善精度-稳定性折中 | 1 天 |
| P3 | 统一归一化策略（delta/state_std） | 75% | 消除系统性偏差 | 半天 |
| P4 | 残差动力学架构（长期） | 70% | 根本性改善 | 3-5 天 |

### 4.2 验收标准调整建议

基于 Agent H 的分析和本审计的综合评估:

**当前标准的可行性**:
- H=1 NMAE < 0.020: sequential 架构下难以达到（当前最佳 0.035，超标 75%）
- H=50 NMAE < 0.548: 需要无约束 sequential + 某种稳定性保证，目前矛盾
- Surv@500 >= 80%: 需要某种收缩/约束机制
- NMAE 单调递增: 自然满足（误差累积的固有特性）

**建议调整**:
1. H=1 阈值放宽至 0.040（允许 sequential 训练的固有退步）
2. 或接受 "safety_blend_0.5 作为工程最优解" 的现实
3. 增加评估段数至 20+ 段以提高统计可靠性
4. 报告置信区间

### 4.3 最终结论

**在不改变架构的前提下，safety_blend_0.5 很可能就是工程极限。**

理由:
1. 所有已测试方案恰好通过 2/4 项标准，无一通过 3 项或更多
2. 精度-稳定性权衡在实验中被反复验证
3. H=1 的精度退化是 sequential 训练的固有特性，非调参可解决
4. 同时满足全部四项标准的概率约 30%（Agent H 估计）

**突破方向**:
1. Scheduled Sampling（短期，低成本，高潜力）
2. 残差动力学架构（中期，高成本，根本性改善）
3. 有界扩张约束（短期，中等成本，改善折中）
