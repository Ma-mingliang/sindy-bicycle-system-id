> 基于 `stage2_dataset_150k.npz` (150,000 样本, 148 episodes) 的定量分析

## 2. 状态间相关性分析

### 2.1 静态相关性 (Pearson r)

```
             e_y     e_psi     theta  theta_dot     delta         v         a
     e_y   1.0000   -0.1545   -0.0013   -0.6357   -0.6079   -0.6377   -0.6242
   e_psi  -0.1545    1.0000   -0.0114    0.0815    0.0172    0.0753    0.1018
   theta  -0.0013   -0.0114    1.0000   -0.0042    0.0263   -0.0025   -0.0040
theta_dot  -0.6357    0.0815   -0.0042    1.0000    0.9882    0.9994    0.9951
   delta  -0.6079    0.0172    0.0263    0.9882    1.0000    0.9862    0.9878
       v  -0.6377    0.0753   -0.0025    0.9994    0.9862    1.0000    0.9921
       a  -0.6242    0.1018   -0.0040    0.9951    0.9878    0.9921    1.0000
```

### 2.2 状态分组

**Group 1 -- 强耦合快速状态 (r > 0.98)**:
- theta_dot, delta, v, a 四者之间相关性极高 (0.986 ~ 0.999)
- 物理原因: 车速 v 直接决定侧倾动力学, 转向角 delta 与侧倾角速度 theta_dot 通过陀螺效应耦合
- 这四个状态本质上共享一个"快速动力学流形"

**Group 2 -- 横向误差状态**:
- e_y 与 Group 1 呈中等负相关 (r = -0.61 ~ -0.64)
- 物理原因: 车速越高/侧倾越大, 横向偏移越小 (控制器在修正)

**Group 3 -- 近独立状态**:
- e_psi 与其他状态相关性很弱 (|r| < 0.15)
- theta 几乎恒定 (std = 0.013, 几乎无变化)

### 2.3 偏相关分析 (控制其他变量后)

| 状态对 | Pearson r | 偏相关 r | 解释 |
|--------|-----------|----------|------|
| e_y <-> e_psi | -0.154 | -0.100 | 弱直接耦合 |
| e_psi <-> delta | 0.017 | **-0.511** | 强条件耦合! 控制其他变量后显著 |
| theta <-> delta | 0.026 | **0.242** | 侧倾-转向耦合 (trail effect) |
| theta_dot <-> v | 0.999 | **0.975** | 极强直接耦合 |
| theta_dot <-> a | 0.995 | **0.728** | 强直接耦合 |
| v <-> a | 0.992 | **-0.616** | 控制后呈负相关 (加减速效应) |

**关键发现**: 偏相关揭示了被静态相关掩盖的真实耦合。e_psi 与 delta 的偏相关从 0.017 跳到 -0.511, 说明在控制了速度和侧倾后, 航向误差与转向角有很强的直接动力学耦合。

## 3. 耦合动力学分析

### 3.1 状态变化相关性 (delta = next_obs - obs)

状态变化之间的相关性揭示了动力学耦合:

```
delta_theta_dot <-> delta_v:    r = 0.768
delta_theta_dot <-> delta_a:    r = 0.421
delta_delta    <-> delta_v:    r = 0.273
delta_delta    <-> delta_a:    r = 0.285
delta_e_y      <-> delta_e_psi: r = -0.104
```

### 3.2 动作如何影响各状态

动作 (转向力矩) 对各状态变化的线性相关性:

| 状态 | action -> delta r | 含义 |
|------|-------------------|------|
| e_y | -0.003 | 几乎无直接影响 |
| e_psi | -0.001 | 几乎无直接影响 |
| theta | -0.001 | 几乎无直接影响 |
| theta_dot | -0.001 | 几乎无直接影响 |
| delta | 0.000 | 几乎无直接影响 |
| v | -0.017 | 微弱影响 |
| a | **-0.115** | 中等影响 (最强) |

**结论**: 动作对状态的影响是非线性的, 线性相关几乎为零。这说明:
1. 动作通过非线性通道影响系统
2. 动作的效应需要通过中间状态 (如 theta_dot) 传播
3. 单步线性模型无法捕捉动作的真实效应

### 3.3 状态间影响的量化 (R-squared 分析)

**e_y (横向误差) 的变化由什么驱动?**
- 仅用 self + action: R^2 = 0.019 (几乎无法预测)
- 用全部状态 + action: R^2 = 0.061
- 主要贡献者: v (+0.031), theta_dot (+0.030), a (+0.029)
- **解释**: e_y 的变化主要由速度和侧倾动力学驱动, 而非直接动作

**e_psi (航向误差) 的变化由什么驱动?**
- 仅用 self + action: R^2 = 0.028
- 用全部状态 + action: R^2 = 0.039
- 主要贡献者: a (+0.003), theta (+0.003), theta_dot (+0.003)
- **解释**: e_psi 变化相对独立, 各状态贡献均匀

**theta_dot (侧倾角速度) 的变化由什么驱动?**
- 仅用 self + action: R^2 = 0.008
- 用全部状态 + action: R^2 = **0.791** (提升 0.783!)
- 主要贡献者: a (+0.737), v (+0.540), delta (+0.091)
- **解释**: theta_dot 高度依赖加速度和速度, 是最"耦合"的状态

**delta (转向角) 的变化由什么驱动?**
- 仅用 self + action: R^2 = 0.003
- 用全部状态 + action: R^2 = **0.323** (提升 0.320)
- 主要贡献者: e_y (+0.127), e_psi (+0.066), v (+0.056)
- **解释**: delta 变化主要由横向/航向误差驱动 (控制器行为)

**v (速度) 的变化由什么驱动?**
- 仅用 self + action: R^2 = 0.006
- 用全部状态 + action: R^2 = **0.359** (提升 0.352)
- 主要贡献者: theta_dot (+0.328), a (+0.275), delta (+0.101)

## 4. 分开预测 vs 联合预测

### 4.1 单步预测精度对比 (线性模型)

| 状态 | 分开预测 RMSE | 联合预测 RMSE | 提升 |
|------|--------------|--------------|------|
| e_y | 0.0824 | 0.0806 | 2.2% |
| e_psi | 0.1895 | 0.1884 | 0.6% |
| theta | 0.0000 | 0.0000 | 3.3% |
| **theta_dot** | **0.0050** | **0.0023** | **54.1%** |
| delta | 0.0034 | 0.0028 | 17.6% |
| **v** | **0.0058** | **0.0047** | **19.7%** |
| a | - | - | - |

**联合预测对 theta_dot 提升 54%, 对 v 提升 20%** -- 这两个是最耦合的状态。

### 4.2 分开预测丢失的信息

1. **跨状态耦合通道**: theta_dot 的 R^2 从 0.008 提升到 0.791, 说明分开预测丢失了 99% 的预测信息
2. **条件依赖**: e_psi 与 delta 的偏相关为 -0.511, 分开预测完全忽略这个关系
3. **非线性交互**: 速度对侧倾动力学的调制效应 (K2*v^2 项) 在分开预测中无法表达
4. **控制器耦合**: delta 的变化由 e_y 和 e_psi 驱动 (R^2 提升 0.32), 分开预测无法捕捉这个闭环效应

### 4.3 分开预测引入的误差

1. **系统性偏差**: 忽略 cross-state 项导致有偏预测
2. **误差累积**: 多步模拟中, 误差通过耦合通道传播:
   - theta_dot 误差 -> v 误差 -> e_y 误差 (级联效应)
   - 10步后, 联合模型的 theta_dot 误差为 0.478, 分开模型为 0.047
3. **物理约束违反**: 分开预测可能产生不满足动力学约束的状态组合

### 4.4 多步误差传播的悖论

线性代理模型的多步模拟显示一个反直觉现象: **联合模型在多步后误差反而更大**。

原因分析:
- 联合模型的线性耦合项放大了初始误差 (eigenvalue > 1 的方向)
- 分开模型通过忽略耦合项, 恰好避免了误差放大
- 这说明: **联合预测需要更准确的模型**, 错误的耦合比没有耦合更糟
- 非线性模型 (如 Wide SiLU NODE) 可以学到正确的耦合, 避免这个问题

## 5. 非线性耦合分析 (互信息)

线性相关无法捕捉非线性耦合。互信息 (Mutual Information) 提供了补充视角:

### 5.1 状态间的互信息

| 状态对 | MI (bits) | 解释 |
|--------|-----------|------|
| e_y <-> e_psi | **1.001** | 最强非线性耦合 |
| e_y <-> delta | 0.816 | 横向误差-转向角 |
| theta_dot <-> delta | 0.725 | 侧倾-转向 |
| theta_dot <-> v | 0.709 | 侧倾-速度 |
| v <-> a | 0.606 | 速度-加速度 |

**关键发现**: e_y 与 e_psi 的互信息最高 (1.0 bit), 但 Pearson 相关只有 -0.154。这说明两者之间存在**强非线性耦合**, 线性模型完全无法捕捉。

### 5.2 状态对变化量的非线性影响

| 输入状态 | 对 delta_e_y 的 MI | 对 delta_e_psi 的 MI | 对 delta_theta_dot 的 MI |
|----------|-------------------|---------------------|-------------------------|
| e_y | 0.222 | 0.242 | 0.326 |
| e_psi | **0.457** | 0.139 | 0.233 |
| theta_dot | 0.063 | 0.207 | 0.433 |
| delta | 0.146 | 0.223 | 0.426 |
| v | 0.066 | 0.221 | 0.373 |
| a | 0.035 | 0.182 | 0.320 |

**e_psi 对 delta_e_y 的非线性影响最大** (MI = 0.457), 但线性相关几乎为零。这证实了航向误差通过非线性机制影响横向误差。

## 6. 物理机制解释

基于 Whipple 自行车动力学模型:

### 6.1 陀螺耦合 (Gyroscopic Coupling)
- 前轮旋转产生陀螺力矩, 将侧倾 (phi) 与转向 (delta) 耦合
- 耦合强度与速度 v 成正比: C1(v) = v * C1_base
- 这解释了 theta_dot <-> v 的极强相关 (r = 0.999)

### 6.2 Trail 效应 (Self-Steering)
- 前叉倾角产生的 trail 使侧倾自动产生转向力矩
- K0[1,0] 项: lean -> steer torque
- 这解释了 theta <-> delta 的偏相关 (r = 0.242)

### 6.3 离心力耦合 (Centrifugal Coupling)
- K2 * v^2 项: 速度越大, 侧倾-转向耦合越强
- 这是非线性耦合的主要来源
- 解释了为什么线性模型的 theta_dot 预测 R^2 只有 0.008

### 6.4 闭环控制器耦合
- LQR/Stanley 控制器将 e_y, e_psi 映射到转向动作
- 动作通过动力学影响 theta_dot, delta, v
- 这形成了 e_y -> action -> theta_dot -> v -> e_y 的闭环
- 解释了 delta 的变化由 e_y (+0.127) 驱动

## 7. Wide SiLU NODE 为什么有效

### 7.1 架构优势
- 5 层, 256 宽的 SiLU 网络: 足够的容量捕捉非线性耦合
- 联合输出: 同时预测所有状态, 隐式保持耦合一致性
- 零初始化最后一层: 从恒等映射开始, 适合残差学习

### 7.2 为什么比分开预测好
1. **捕捉非线性耦合**: SiLU 激活函数可以表示 e_y<->e_psi 的非线性关系 (MI = 1.0 bit)
2. **共享特征**: 隐层共享的特征表示自然编码了跨状态依赖
3. **速度调制效应**: 网络可以学到 K2*v^2 类型的非线性项
4. **闭环效应**: 联合预测自然捕捉 e_y -> action -> theta_dot -> v 的反馈环

### 7.3 为什么比 GP 好 (对复杂状态)
- GP 假设平稳协方差结构, 无法捕捉速度相关的非线性耦合
- GP 的计算复杂度 O(N^3) 限制了训练数据量
- Wide SiLU NODE 可以在全部 150k 数据上训练

## 8. 进一步改进建议

### 8.1 架构改进
1. **残差连接**: 添加 skip connection, 改善梯度流
2. **注意力机制**: 让网络学习哪些状态对之间最重要
3. **物理约束层**: 在输出层添加动力学约束 (如能量守恒)

### 8.2 训练改进
1. **多步损失**: 训练时使用 5-10 步的展开损失, 而非单步损失
2. **物理正则化**: 添加约束使预测满足 M*q_ddot + C1*v*q_dot + (K0+K2*v^2)*q = F
3. **课程学习**: 先训练简单状态 (theta, v), 再训练复杂状态 (e_y, e_psi)

### 8.3 数据改进
1. **增加多样性**: 当前 148 episodes 可能不够覆盖状态空间
2. **平衡采样**: 当前数据中 theta 几乎恒定, 需要更多侧倾变化的数据
3. **主动收集**: 在模型预测误差大的区域主动采集数据

### 8.4 混合策略
1. **分层预测**: 先预测快状态 (theta_dot, v, a), 再用结果预测慢状态 (e_y, e_psi)
2. **物理-神经混合**: 用解析模型处理线性耦合 (C1, K0), 用 NN 处理非线性残差
3. **集成方法**: 多个 Wide SiLU NODE 的集成, 捉捕不确定性

---

## 9. 核心结论

1. **theta_dot, delta, v, a 是强耦合组** (r > 0.98), 必须联合预测
2. **e_y 与 e_psi 存在强非线性耦合** (MI = 1.0 bit), 线性相关 (r = -0.15) 无法捕捉
3. **分开预测丢失 theta_dot 99% 的预测信息** (R^2: 0.008 vs 0.791)
4. **联合预测需要高容量非线性模型**, 错误的耦合比没有耦合更糟
5. **Wide SiLU NODE 有效因为**: 联合输出 + SiLU 非线性 + 充足容量
6. **最大改进空间**: 多步训练损失 + 物理正则化
