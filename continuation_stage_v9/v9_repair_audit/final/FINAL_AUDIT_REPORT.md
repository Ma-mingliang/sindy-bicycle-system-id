### 1.2 核心矛盾仲裁: BUG-002 归一化不匹配

**Agent G 的降级论证** (被 Agent I 驳回):
- G 认为 V9 predict() 单步推理数学自洽，因此归一化非 bug
- G 将"predict() 正确"等同于"训练 rollout 正确"

**Agent I 的驳回理由**:
- predict() 正确是因为反归一化链 `dsdt_norm * delta_std * dt` 完美抵消
- 但训练 rollout 使用不同路径: `s_cur + dsdt * dt`，不经过反归一化
- **数学证明**: rollout 中 `state/state_std + delta/delta_std` ≠ target `state/state_std + delta/state_std`
- 对 e_y 分量: `delta_std ~ 0.01m`, `state_std ~ 0.5m`，比值约 50 倍
- **结论**: 每步 rollout 增量被放大 50 倍，20 步后灾难性累积

**最终判定**: BUG-002 维持 CRITICAL。Agent G 的降级不成立。

### 1.3 V9 "常数预测"假说 - 精确描述

**Agent I 的仲裁**: V9 不是"字面常数预测"，而是"单步有效、多步无效的近恒等映射"。

| 描述 | Agent | 准确性 |
|------|-------|--------|
| "V9 NMAE 单调递增，非常数预测" | G | 数据正确，但结论过度外推 |
| "V9 多步损失被 shuffle 破坏，退化为单步学习器" | D | 机制正确 |
| "V9 是近恒等映射" | I | **最精确** — 两者共存 |

**解释**: 单步损失让模型学到局部动力学（NMAE 不是常数），但多步动力学从未被有效训练（H=500 NMAE≈1.0）。100% 存活率是因为单步误差小，累积 500 步后恰好未超出宽松的物理限制。

### 2.2 关键发现

**发现 1: 多种子方差极大**
- no_contract seed=44: 100% 存活，H=500 NMAE=1.284
- no_contract seed=43,45: 0% 存活，H=500 NMAE=0.47-0.47
- **结论**: 单次实验结果不可靠，必须多种子验证

**发现 2: 扩展课程导致常数预测**
- ext_400ep_h50: H=20 后 NMAE 恒定 (0.299)，生存率 0%
- **证实了 Agent G 的发现**: 长训练 + 长 rollout 可能导致模型坍缩

**发现 3: 收缩性强度与精度的关系**
- λ=0.02: H=500 NMAE=0.937 (最佳)
- λ=0.05: H=500 NMAE=0.958
- λ=0.10: H=500 NMAE=0.962
- **结论**: 收缩性越强，长 horizon 精度越差（符合预期）

**发现 4: 所有收缩变体 H=50 NMAE > 0.548**
- 最佳: strong_contract_010 H=50=0.627 (仍超标 14%)
- **结论**: 收缩性约束系统性降低中 horizon 精度

## 8. 结论

### 8.1 一句话总结

**V9 存在两个确认的 CRITICAL bug（shuffle 和归一化不匹配），修复后 V12 在短 horizon 精度上显著改善，但引入了精度-稳定性权衡问题——没有任何方案同时满足全部 4 项验收标准。**

### 8.2 核心洞察

1. **BUG-002 归一化不匹配是真实的 CRITICAL bug**: 每步 rollout 增量被放大 ~50 倍（e_y 分量），20 步后灾难性累积。Agent G 的降级被 Agent I 驳回。
2. **V9 是"近恒等映射"**: 单步有效（NMAE=0.006），多步无效（NMAE=0.998），不是字面常数预测但多步动力学未被学习。
3. **精度-稳定性权衡是物理约束**: 准确的动力学包含局部扩张区域，但稳定的 rollout 要求全局收缩。
4. **H=1 精度来自 shuffle 训练**: sequential 训练固有地降低单步精度（0.006→0.035-0.056）。
5. **评估方法有偏差**: 存活率指标过于宽松，NMAE 有幸存者偏差。
6. **验收标准需要调整**: H=1 < 0.020 对 sequential 架构可能不可达。

### 8.3 下一步行动

1. **与用户确认**: 是否调整验收标准？（建议 H=1 放宽至 0.040）
2. **实施 Scheduled Sampling**: 最有潜力的低成本改进（文献强烈推荐）
3. **有界扩张约束**: 替代全局收缩，改善精度-稳定性折中
4. **改进评估方法**: 消除幸存者偏差，增加评估段数
5. **考虑残差架构**: 长期根本改进方向
