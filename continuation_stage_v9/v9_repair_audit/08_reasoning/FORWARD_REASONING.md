# 正向推理（第 18 章）

## 推理链 1: 从 Shuffle Bug 到常数预测

**前提**: shuffle=True 破坏时间顺序

**推理**:
1. DataLoader 随机打乱时间步 → batch 中 `sb[i+1]` 不是 `sb[i]` 的后继
2. 多步 rollout 假设时间连续性 → 目标 `sb[step+1]` 是随机状态
3. MSE 损失在随机目标上 → 梯度为噪声
4. 有效训练信号仅来自单步损失
5. 单步损失的最优解: 预测均值 delta（归一化空间中接近零）
6. 近零 delta → 状态几乎不变 → 常数预测

**结论**: shuffle=True → 多步损失失效 → 单步主导 → 常数预测

**置信度**: 95%

---

## 推理链 2: 从常数预测到虚假存活率

**前提**: 模型预测近零 delta

**推理**:
1. 初始状态在物理限制内（测试数据正常）
2. 预测 delta ≈ 0 → 状态 ≈ 初始状态
3. 初始状态在限制内 → 预测状态也在限制内
4. 无论 rollout 多长，状态不移动 → 存活率 100%

**结论**: 常数预测 → 虚假 100% 存活

**置信度**: 99%

---

## 推理链 3: 从 Shuffle 修复到存活率崩溃

**前提**: 修复 shuffle，多步损失变得有意义

**推理**:
1. 有意义的多步损失 → 模型学习实际动力学
2. 实际动力学 → 预测更大的状态变化
3. 更大的状态变化 → 长 horizon 累积
4. 累积误差 → 某些状态超出物理限制
5. 超出限制 → 存活检查失败

**证据**: v9_fixed_seq H=500 每状态 NMAE:
| 状态 | V9 基线 | v9_fixed_seq | 改善 |
|------|---------|--------------|------|
| e_y | 1.28 | 0.42 | 3.0x |
| e_psi | 1.72 | 0.44 | 3.9x |

模型大幅更精确，但精确的预测会超出限制。

**结论**: 修复 shuffle → 学到动力学 → 预测变大 → 超出限制 → 存活崩溃

**置信度**: 97%

---

## 推理链 4: 从收缩性到精度-稳定性权衡

**前提**: 添加收缩性正则化（惩罚正 Jacobian 特征值）

**推理**:
1. Jacobian 特征值 ≤ 0 → 局部收缩性
2. 收缩性 → 相邻轨迹收敛 → 状态不发散
3. 但自行车动力学本身可能是扩张的（例如转弯时横向误差增大）
4. 强制收缩 → 无法学习真实扩张动力学
5. 短 horizon: 约束防止不稳定，改善精度
6. 长 horizon: 约束防止学习真实动力学，恶化精度

**证据**:
| Horizon | 无收缩 | 有收缩 | 变化 |
|---------|--------|--------|------|
| H=1 | 0.056 | 0.035 | -37% |
| H=50 | 0.385 | 0.647 | +68% |
| H=500 | 0.476 | 0.958 | +101% |

**结论**: 收缩性 → 短 horizon 改善 + 长 horizon 恶化 = 精度-稳定性权衡

**置信度**: 95%

---

## 推理链 5: 从安全混合到部分突破

**前提**: 安全混合推理（正常用 sequential，接近限制用 contractive）

**推理**:
1. 大部分时间用 sequential 模型 → 保持精度
2. 接近物理限制时切换到 contractive → 保证安全
3. 切换阈值 = 物理限制的 50%
4. 在安全区域: sequential 提供精确预测
5. 在危险区域: contractive 提供稳定预测

**结果**: H=500 NMAE=0.946 (改善 5.2%), 100% 存活

**局限**: H=50 退步 16%（0.637 vs 0.548）

**结论**: 安全混合部分突破权衡，但不是完全解决

**置信度**: 90%

---

## 综合推理结论

1. **根因链条**: shuffle → 多步失效 → 常数预测 → 虚假存活
2. **修复后果**: 修复 shuffle → 学到动力学 → 存活崩溃
3. **权衡本质**: 收缩性用长 horizon 精度换存活
4. **部分突破**: 安全混合推理实现 5.2% 改善 + 100% 存活
5. **根本限制**: 精度-稳定性权衡可能需要全新方法才能完全解决
