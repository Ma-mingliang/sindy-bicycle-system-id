# 反向推理（第 19 章）

## 从目标反推必要条件

### 目标: H=500 NMAE < 0.998 且 存活率 100%

**反推链**:
1. H=500 NMAE < 0.998 → 模型必须预测有意义的状态变化（不能是常数预测）
2. 有意义的状态变化 → 多步损失必须有效
3. 多步损失有效 → 必须修复 shuffle + 归一化
4. 修复后学到动力学 → 预测会变大
5. 预测变大 → 可能超出物理限制
6. 不超出限制 → 需要某种约束机制

**必要条件**:
- [x] 修复 shuffle (SequentialSegmentDataset)
- [x] 修复归一化 (deltas/state_std)
- [ ] 约束机制防止状态超出限制
- [ ] 约束不能过度损害精度

### 目标: H=50 NMAE < 0.548

**反推链**:
1. H=50 NMAE < 0.548 → 中 horizon 必须精确
2. 精确的中 horizon → 模型必须学到 50 步的动力学
3. 50 步动力学 → 训练 rollout 至少 50 步
4. 训练 rollout 50 步 → 课程必须包含 H=50
5. 但 V9 课程上限是 20 → 需要扩展课程

**必要条件**:
- [x] 扩展课程到至少 50
- [ ] 长 rollout 训练不崩溃

### 目标: H=1 NMAE < 0.020

**反推链**:
1. H=1 NMAE < 0.020 → 单步必须非常精确
2. 单步精度 → 模型必须准确学习一步动力学
3. 但添加收缩性后 H=1 NMAE = 0.035 → 收缩性损害单步精度
4. 需要约束不影响单步精度

**必要条件**:
- [ ] 约束仅在长 horizon 时激活，不影响单步

## 矛盾分析

| 矛盾 | 描述 | 可能解决方向 |
|------|------|-------------|
| 精度 vs 精度 | 收缩性改善 H=1 但恶化 H=50 | 状态相关约束 |
| 精度 vs 存活 | 学到动力学就可能发散 | 安全混合/投影约束 |
| 课程 vs 稳定 | 长 rollout 训练可能崩溃 | 渐进式增长 |

---

## 反向推理结论

要同时满足所有验收标准，需要:
1. 修复 shuffle + 归一化（已验证）
2. 约束机制: 状态相关收缩性或投影约束
3. 扩展课程到 H=50+
4. 约束不能损害单步精度

**最可能的解决方案**: 状态相关收缩性 + 安全混合推理
