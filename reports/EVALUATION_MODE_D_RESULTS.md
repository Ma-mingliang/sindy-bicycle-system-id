## 3. Mode D 的特点

1. **真实闭环**: 模型状态影响力矩，力矩影响状态
2. **双向误差传播**: 模型误差通过控制器反馈放大或抑制
3. **最严格评估**: 最接近实际使用场景

### 3.1 与 Mode C 的关键差异

| 方面 | Mode C | Mode D |
|------|--------|--------|
| tau 来源 | s_real | s_model |
| 误差传播 | 单向 | 双向 |
| 稳定性 | 较好 | 可能更差或更好 |

## 4. 关键发现

1. **GP标准模型在Mode D下完美跟踪**: 1000步 MAE < 0.00001 rad，LQR控制器完美补偿GP预测误差
2. **SINDy在闭环控制下表现优异**: 1000步 MAE 仅 0.008 rad (0.46°)，且误差随时间递减
3. **线性化模型在Mode D下立即发散**: 10步 MAE 已达 2.566 rad
4. **GP-B4稀疏模型精度差**: Nystroem近似损失精度，1000步 MAE = 28.85 rad
5. **delta_dot 是最难控制的状态**: SINDy 在 delta_dot 上的误差是其他状态的 10-100 倍

---

## 5. 为什么 GP 标准模型在 Mode D 下零误差？

GP标准模型在Mode D下实现零误差的原因：
1. **GP单步预测极精确**: Mode A MAE ≈ 0 (归一化后)
2. **LQR控制器完美补偿**: 控制器用模型状态计算的力矩与真实状态几乎相同
3. **闭环反馈消除误差**: 模型和真实系统同步运行，误差不累积

这不是模型"完美"，而是闭环控制系统的鲁棒性。
