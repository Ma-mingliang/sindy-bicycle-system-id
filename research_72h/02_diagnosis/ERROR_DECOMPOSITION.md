## 2. 各误差来源分析

### 2.1 模型误差 (E_model)

**来源**: 神经网络 f_θ 不能完美近似真实动力学 f*

**量化估计**:
- 单步预测 NMAE = 0.0051 (H=1)
- 这是模型误差的下界
- 假设单步误差主要来自模型误差

**影响因素**:
- 网络容量 (9,351 参数)
- 训练数据量 (150k 样本)
- 训练策略 (课程学习)
- 激活函数 (Tanh)

### 2.2 积分误差 (E_integration)

**来源**: Euler 方法的局部截断误差累积

**理论分析**:
- Euler 局部截断误差: O(dt²) = O((1/30)²) ≈ 0.001
- 全局截断误差: O(dt) = O(1/30) ≈ 0.033
- H 步后累积误差: O(H * dt²)

**量化估计**:
- 假设单步积分误差 ≈ 0.001
- H=100 累积误差 ≈ 0.1
- H=500 累积误差 ≈ 0.5
- 但实际误差增长非线性，可能更大

**区分实验**:
- 比较 Euler vs RK4
- 如果 RK4 显著改善，说明积分误差是主要瓶颈

### 2.3 数据误差 (E_data)

**来源**: 训练数据不能覆盖所有工况

**量化估计**:
- 速度范围 [0.54, 0.66]，极窄
- 可能存在 OOD 区域
- 长 rollout 可能进入未见区域

**影响因素**:
- 数据覆盖度
- 数据质量 (噪声、异常值)
- 归一化统计量

## 3. 误差随 Horizon 增长模式

### 理论模式

| 模式 | 公式 | 特征 |
|------|------|------|
| 线性增长 | E(H) = a*H | 积分误差主导 |
| 指数增长 | E(H) = b*exp(c*H) | 不稳定系统 |
| 平台模式 | E(H) → L | 稳定系统 |
| 跳跃模式 | E(H) 在某点突变 | 分岔/混沌 |

### v9 实际模式

| Horizon | NMAE | 增长率 |
|---------|------|--------|
| H=1 | 0.0051 | - |
| H=10 | 0.0628 | 12.3x |
| H=50 | 0.4557 | 7.3x |
| H=100 | 0.5064 | 1.1x |
| H=200 | 0.4737 | 0.9x |
| H=500 | 0.5529 | 1.2x |

**观察**:
- H=1→10: 误差快速增长 (12x)
- H=10→50: 误差快速增长 (7x)
- H=50→100: 误差增长放缓 (1.1x)
- H=100→200: 误差略微下降 (0.9x) — 可能是平台期
- H=200→500: 误差缓慢增长 (1.2x)

**结论**:
- 误差不是单调增长
- 存在平台期 (H=100-200)
- H=200 后可能有分岔

## 5. 误差分解实验设计

### 实验 A: 模型误差 vs 积分误差

**方法**:
1. 使用真实导数 (从数据计算) + Euler 积分
2. 使用真实导数 + RK4 积分
3. 使用 v9 导数 + Euler 积分
4. 使用 v9 导数 + RK4 积分

**预期**:
- 如果 1≈2 且 3≈4: 积分误差不重要
- 如果 1≈2 但 3≪4: 积分误差对 v9 重要
- 如果 1≪3: 模型误差是主要瓶颈

### 实验 B: 单步 vs 多步误差

**方法**:
1. 比较 H=1 误差 (单步)
2. 比较 H=10 误差 / 10 (平均每步)
3. 比较 H=100 误差 / 100 (平均每步)

**预期**:
- 如果平均每步误差恒定: 线性累积
- 如果平均每步误差增长: 非线性放大
- 如果平均每步误差下降: 平台效应
