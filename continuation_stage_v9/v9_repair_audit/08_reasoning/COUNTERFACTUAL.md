# 反事实分析（第 20 章）

## 反事实 1: 如果从未使用 shuffle=True

**假设**: V9 从一开始就使用 SequentialSegmentDataset

**推理**:
1. 多步损失从第一天就有效
2. 模型会学到实际动力学
3. 但没有收缩性约束 → 长 horizon 会发散
4. 结果: 精确但不稳定的模型（类似 v9_fixed_seq）

**结论**: shuffle=True 延迟了问题的发现，但不是唯一根因

---

## 反事实 2: 如果使用 V12 归一化（deltas/state_std）

**假设**: V9 一开始就用 `deltas / state_std` 作为训练目标

**推理**:
1. 归一化空间统一 → 多步 rollout 无空间不匹配
2. 但 shuffle 仍然存在 → 多步损失仍然无效
3. 结果: 与 V9 基线相同

**结论**: 仅修复归一化不够，必须同时修复 shuffle

---

## 反事实 3: 如果训练 rollout 直接到 H=500

**假设**: 课程从一开始就是 '1,5,10,20,50,100,200,500'

**推理**:
1. 即使有 shuffle bug，长 rollout 也可能提供一些有用信号
2. 但 shuffle 使长 rollout 的目标是随机状态
3. 长 rollout + 随机目标 → 梯度可能更混乱
4. 结果: 可能比 V9 基线更差

**结论**: 长 rollout 不能弥补 shuffle bug

---

## 反事实 4: 如果一开始就添加收缩性

**假设**: V9 训练时就包含 Jacobian 正则化

**推理**:
1. 收缩性约束 Jacobian 特征值
2. 但 shuffle 使多步损失无效 → 模型仍学常数预测
3. 常数预测的 Jacobian 接近零 → 收缩性损失 ≈ 0
4. 收缩性对常数预测无效
5. 结果: 与 V9 基线相同

**结论**: 收缩性在 shuffle 存在时无效

---

## 反事实 5: 如果使用 Teacher Forcing 评估

**假设**: 评估时每步用真实状态修正（teacher forcing）

**推理**:
1. 每步从真实状态开始 → 误差不累积
2. H=500 NMAE ≈ H=1 NMAE ≈ 0.006
3. 存活率 = 100%（真实状态始终在限制内）

**结论**: Teacher forcing 会隐藏长 horizon 问题，不适合评估

---

## 反事实 6: 如果物理限制更宽松

**假设**: 物理限制放宽 10 倍（e_y=50, v=50）

**推理**:
1. v9_fixed_seq 的预测虽然大，但可能不超出宽松限制
2. 存活率可能恢复到 100%
3. 但 NMAE 不变

**结论**: 存活率依赖于物理限制的定义

---

## 反事实综合结论

| 反事实 | 关键发现 |
|--------|----------|
| 无 shuffle | 问题暴露但不解决（还需收缩性） |
| V12 归一化 | 不够，必须同时修 shuffle |
| H=500 训练 | 不能弥补 shuffle bug |
| 一开始就收缩 | 对常数预测无效 |
| Teacher forcing | 会隐藏问题 |
| 宽松限制 | 存活率依赖限制定义 |

**核心洞察**: 问题不是单个 bug，而是多个 bug 的交互。必须同时修复 shuffle + 归一化，并添加约束机制。
