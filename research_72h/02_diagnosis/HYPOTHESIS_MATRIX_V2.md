## 1. 根因揭示

**核心问题**: Neural ODE 学到了动力学，但积分误差累积导致长期发散。GP 没学到动力学（delta→0），所以长期稳定但不准确。

**目标**: 找到一种方法，既能学到真正动力学，又能控制误差累积。

## 3. 新实验设计

### 实验 1: 约束 Neural ODE (H11)

**目的**: 测试稳定性约束是否能控制误差累积

**方法**:
- 添加 Jacobian 范数约束：||J|| < threshold
- 添加 Lyapunov 约束：dV/dt < 0
- 测试不同约束强度

**预期**: 如果约束有效，H=200/500 应该改善

**通过条件**: H=500 NMAE 下降 > 20%

### 实验 2: 物理残差模型 (H12)

**目的**: 测试物理先验是否能改善长期预测

**方法**:
- 使用已知的自行车动力学方程作为基础
- Neural ODE 学习残差
- 测试不同残差权重

**预期**: 如果物理先验有效，H=100+ 应该改善

**通过条件**: H=500 NMAE 下降 > 15%

### 实验 3: 混合方法 (H13)

**目的**: 测试短期-长期切换是否能结合两者优势

**方法**:
- H<50 使用 Neural ODE
- H≥50 使用 GP（或物理模型）
- 测试不同切换点

**预期**: 如果切换有效，短期和长期都应该改善

**通过条件**: H=1 保持 < 0.01，H=500 < 0.45

### 实验 4: 不确定性门控 (H14)

**目的**: 测试不确定性门控是否能改善 OOD 表现

**方法**:
- 使用 GP 不确定性进行 OOD 检测
- OOD 时回退到物理模型
- 测试不同阈值

**预期**: 如果门控有效，OOD 表现应该改善

**通过条件**: OOD NMAE 下降 > 30%
