## 2. 第一性原理分析

### 2.1 自行车动力学的本质

**物理特性**:
- 非线性耦合系统
- 不稳定系统 (g/h = 12.2625)
- 多尺度动力学 (快: delta_dot, 慢: e_y)

**数据特性**:
- 归一化数据 (不能用物理公式)
- 速度范围窄 [0.54, 0.66]
- e_y, e_psi 变化本质上随机 (SNR=0.0011)

### 2.2 状态耦合分析

**强耦合**:
- theta_dot, delta, v: 相关性 > 0.98
- e_y, e_psi: 互信息 = 1.0 bit (最强非线性耦合)

**弱耦合**:
- v: 几乎常数 (变化 std = 0.000043)
- delta_dot: 恒为零

### 2.3 误差累积机制

**Jacobian 谱半径决定误差累积**:
- ρ > 1: 指数发散
- ρ = 1: 线性累积
- ρ < 1: 饱和

**不同方法的 Jacobian**:
- Wide SiLU NODE: 高维隐藏层控制 Jacobian
- Coupling Network: 瓶颈导致 Jacobian 秩低
- GP: 近恒等映射 (delta≈0)

## 3. 为什么不同方法有效/无效？

### 3.1 Wide SiLU NODE (Primary = 0.3930, +23.1%)

**为什么有效**:
1. **SiLU 激活** — 不饱和，梯度流好
2. **256×5 架构** — 足够容量捕捉耦合
3. **联合预测** — 保持状态间耦合
4. **无瓶颈** — 所有信息自由流动

**为什么长期恶化**:
1. **误差累积** — Jacobian 谱半径 > 1
2. **数据覆盖度不足** — 速度范围窄
3. **无物理约束** — 从零学习

### 3.2 Coupling Network (32 dim) (Primary = 0.7566, -48%)

**为什么失败**:
1. **32D 瓶颈** — 无法编码完整耦合信息
2. **解码器独立** — 无法保证物理一致性
3. **Jacobian 秩低** — 误差方向不受控

**关键发现**: theta_dot 的 R² 从 0.008 跳到 0.791 (跨状态信息占 99%)

### 3.3 Improved Coupling Network (256 dim) (Primary = 0.4712, +7.8%)

**为什么有效**:
1. **256D 耦合向量** — 减少信息瓶颈
2. **解码器访问所有状态** — 保持耦合
3. **残差连接** — 直接访问原始状态

**为什么比 Wide SiLU 好**:
- H=50: +92% vs Wide SiLU
- H=100: +62% vs Wide SiLU
- H=200: +36% vs Wide SiLU

### 3.4 Kinematic Constrained (Primary = 0.5253, -2.8%)

**为什么短期好**:
- 运动学公式提供"恢复力"
- 线性近似对小扰动有效

**为什么长期差**:
- 运动学公式不适用于归一化数据
- 线性近似对大扰动失效

## 4. 核心洞察

### 4.1 耦合是关键

**所有成功的方法都保持了状态耦合**:
- Wide SiLU NODE: 联合预测
- Improved Coupling: 256D 耦合向量 + 解码器访问所有状态

**所有失败的方法都丢失了耦合**:
- Coupling Network (32D): 瓶颈太小
- Per-State: 分开预测丢失信息

### 4.2 容量很重要

**更大的容量 → 更好的性能**:
- Coupling 32D: Primary = 0.7566 (失败)
- Coupling 256D: Primary = 0.4712 (成功)
- Wide SiLU 267K: Primary = 0.3930 (成功)

### 4.3 长期预测的根本挑战

**所有方法在 H=200/500 都恶化**:
- 误差累积是不可避免的
- 需要更强的约束或不同的范式
