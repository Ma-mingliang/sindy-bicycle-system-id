## 2. 关键发现

### 2.1 GP标准模型在Mode D下完美跟踪

GP标准模型在Mode D (闭环) 下实现了 **零误差** 跟踪。原因:
- GP 单步预测极精确 (Mode A MAE ≈ 0)
- LQR 控制器用模型状态计算的力矩与真实状态几乎相同
- 因此模型和真实系统同步运行，误差不累积

### 2.2 集成模型显著优于单一GP

| 对比 | Mode C 500步 | Mode D 1000步 |
|------|-------------|---------------|
| gp_standard | 12.149 | 0.000 |
| gp_ensemble_7_5 | 0.252 | 0.074 |
| 改进倍数 | **48×** | - |

集成模型 (GP+NN+DAgger) 在开环/混合模式下大幅优于单一GP。

### 2.3 Mode D 下误差递减现象

SINDy 和集成模型在 Mode D 下误差随时间递减:
- SINDy: 0.162 (10步) → 0.008 (1000步)
- gp_ensemble_7_5: 0.265 (10步) → 0.074 (1000步)

原因: LQR 控制器逐步纠正偏差，闭环反馈抑制误差累积。

### 2.4 7+5 优于 5+3

| 模型 | Mode D 1000步 | Mode C 500步 |
|------|---------------|-------------|
| gp_ensemble_5_3 | 0.145 | 0.320 |
| gp_ensemble_7_5 | 0.074 | 0.252 |
| 改进 | **2×** | **1.3×** |

更多NN模型和DAgger轮次带来更好的精度。

### 2.5 Mode C 比 Mode D 更差

在 Mode C 中，控制器用真实状态计算力矩，但模型用自身预测。这导致:
- 模型和真实系统使用不同的力矩
- 误差快速累积
- GP 标准模型 500 步 MAE = 12.15 rad

### 2.6 GP-B4 稀疏模型不如标准GP

GP-B4 (Nystroem 近似) 在所有模式下都比标准GP差:
- Mode C 500步: 20.97 vs 12.15
- Mode D 500步: 14.53 vs 0.000
- 原因: Nystroem 近似损失了精度

## 6. 结论

1. **GP标准模型是最可靠的**: 在Mode D下实现零误差跟踪
2. **集成模型 (7+5) 是最佳整体**: Mode D 1000步 MAE = 0.074 rad，提供不确定性估计
3. **SINDy适合快速原型**: 闭环控制下1000步MAE仅0.008 rad
4. **Mode D比Mode C更有意义**: 闭环评估更接近实际使用
5. **集成训练时间长**: 7+5 配置需要 ~54 分钟训练
