==========================================================================
  SINDy 无人自行车系统辨识 - 实验报告
==========================================================================

项目名称: 基于 SINDy 的无人自行车系统辨识
参考论文: 马明亮, "基于 SINDy 与 TD-MPC2 的无人自行车系统辨识与模型强化学习研究"

==========================================================================
1. 方法概述
==========================================================================

状态定义 (8维外环):
  x = [ey, eψ, v, θ, θ̇, k, δ, δ̇]
  - ey:      横向误差 (m)
  - eψ:      航向误差 (rad)
  - v:       纵向速度 (m/s)
  - θ:       横滚角 (rad)
  - θ̇:       横滚角速度 (rad/s)
  - k:       参考路径曲率 (1/m)
  - δ:       转向角 (rad)
  - δ̇:       转向角速度 (rad/s)

控制输入: a (转向控制量)

辨识目标: s_{t+1} = s_t + f_SINDy(s_t, a_t) + ξ_t

==========================================================================
2. 数据采集
==========================================================================

采样策略: 分层采样 (直线/曲率连续变化/急弯)
采样频率: 30 Hz (dt = 1/30 s)
数据量:   2083 个有效样本 (经过滤后)
激励方式: PD平衡控制器 + 随机探索混合策略

归一化参数 (来自论文):
  ey/10, eψ/1.57, v/5, θ/1.57, θ̇/10, k×8, δ/0.785, δ̇/3

==========================================================================
3. SINDy 辨识结果
==========================================================================

字典函数: 二阶多项式库 (常数 + 线性 + 二次项, 共 55 项)
稀疏回归: STLSQ (Sequentially Thresholded Least Squares)
最佳参数: threshold=0.1, alpha=0.1

辨识得到的状态转移方程:

  Δey ≈ 0
    → 横向误差变化在当前字典中不可辨识

  Δeψ ≈ +0.117 * v*δ
    → 航向误差变化由速度和转向角的乘积驱动

  Δv ≈ 0
    → 速度保持恒定 (假设纵向速度不变)

  Δθ ≈ +0.214 * θ̇
    → 横滚角变化等于横滚角速度 (运动学关系)

  Δθ̇ ≈ +0.105 * v*δ
    → 横滚角加速度由速度和转向角驱动 (离心效应)

  Δk ≈ 0
    → 曲率在单步中不变

  Δδ ≈ -0.497*θ -0.492*δ +0.137*δ̇ -0.284*v*θ -0.152*v*θ̇ +1.348*v*δ
    → 转向角变化由横滚-转向耦合和速度效应驱动

  Δδ̇ ≈ +0.14 +0.31*ey -0.43*v -8.19*θ -6.41*δ -0.59*δ̇ +0.28*a +...
    → 转向角加速度是最复杂的动态, 包含31个活跃项

==========================================================================
4. 物理意义解释
==========================================================================

关键发现:
1. 横滚-转向耦合: Δδ 中 θ 的系数为 -0.497, 反映了横滚角对转向的影响
2. 速度-转向耦合: Δδ 中 v*δ 的系数为 +1.348, 反映了高速时转向灵敏度增加
3. 离心效应: Δθ̇ = 0.105*v*δ, 速度和转向产生横滚加速度
4. 控制响应: Δδ̇ 中 a 的系数为 +0.28, 转向控制量直接影响转向角加速度

这些关系与 Whipple 自行车模型的物理直觉一致。

5. 模型性能
==========================================================================

训练集: 1666 个样本 (80%)
测试集: 417 个样本 (20%)

性能指标:
  - 平均 R²:    0.8470
  - 平均 RMSE:  0.0333
  - 活跃项数:   40 (共 55 个字典项)

各状态维度性能:
  - ey:     R²=-0.000, RMSE=0.0023  (常数假设)
  - epsi:   R²=0.969,  RMSE=0.0031  (优秀)
  - v:      R²=1.000,  RMSE=0.0000  (常数假设)
  - theta:  R²=0.966,  RMSE=0.0014  (优秀)
  - theta_dot: R²=0.860, RMSE=0.0061 (良好)
  - k:      R²=1.000,  RMSE=0.0000  (常数假设)
  - delta:  R²=0.998,  RMSE=0.0111  (优秀)
  - delta_dot: R²=0.985, RMSE=0.242 (良好)

8. 与 TD-MPC2 的集成说明
==========================================================================

论文的第二部分将 SINDy 世界模型与 TD-MPC2 结合:

1. SINDy 提供显式转移先验: f_SINDy(s, a)
2. TD-MPC2 学习潜在空间动力学
3. 两者在滚动规划中并行参与动作评估
4. SINDy 约束局部动力学一致性, TD-MPC2 修正长期回报

本复现完成了 SINDy 辨识部分。TD-MPC2 部分需要:
- 定义连续动作 MDP (八维状态, 转向控制, 奖励函数)
- 实现 TD-MPC2 的潜在空间学习
- 将 SINDy 模型注入规划阶段
