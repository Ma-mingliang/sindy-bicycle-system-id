## 1. 项目概述

本项目是无人自行车动力学预测模型的系统辨识研究。当前基线是 v9 Neural ODE，使用 7D 状态空间学习自行车的连续时间动力学。

### 研究目标
- 建立准确的自行车"世界模型"预测未来状态
- 支持 MPC（模型预测控制）规划
- 在 H=1 到 H=1000 步的预测中保持准确性

## 2. 状态空间

### 8D 原始状态
| 索引 | 符号 | 含义 | 单位 | 范围 |
|------|------|------|------|------|
| 0 | e_y | 横向位置误差 | m | [-0.5, 0.5] |
| 1 | e_psi | 航向角误差 | rad | [-1.0, 1.0] |
| 2 | v | 纵向速度 | m/s | [0.54, 0.66] |

| 7 | delta_dot | 转角变化率 | rad/s | [-1.0, 1.0] |

### 7D 使用状态 (v9)
v9 使用 `IDX_7D_FROM_8D = [0, 1, 2, 3, 4, 6, 7]`，即去掉 k（恒为0）。

- 大部分状态已归一化到 [-1, 1] 范围

## 4. v9 Neural ODE 架构

### 模型结构
```
dx/dt = f_θ(x, u)

输入: [x(7维), u(1维)] = 8维
隐藏层1: Linear(8, 64) + Tanh
隐藏层2: Linear(64, 64) + Tanh
隐藏层3: Linear(64, 64) + Tanh
输出层: Linear(64, 7)

参数量: 9,351
积分方法: Euler (x_{t+1} = x_t + dt * f_θ(x_t, u_t))
```

### 训练策略
- 多步 rollout 课程学习: 1 → 5 → 10 → 20 步
- 一致性损失: theta_dot 与 theta 的物理关系
- Jacobian 正则化: 平滑动力学函数
- 学习率调度: 余弦退火
- 梯度裁剪: max_norm=1.0
- 训练轮数: 200 epochs
- 批大小: 256

### 归一化
- 状态归一化: `s_norm = s / state_std`
- 动作归一化: `a_norm = a / action_std`
- 导数目标: `dsdt_norm = delta / (delta_std * dt)`

## 7. 已知问题

1. **横向状态误差大**: e_y 和 e_psi 在 H=100+ 时 NMAE > 0.7
2. **误差波动大**: 变异系数 60-83%
3. **H≈400 误差跳跃**: 约13秒处误差突然增大
4. **数据集有限**: 仅 148 个 episode，速度范围窄
5. **平台期验证不一致**: 不同评估标准导致结论冲突
