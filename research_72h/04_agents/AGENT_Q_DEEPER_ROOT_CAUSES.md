## 1. 数据层面问题

### 1.1 数据分布严重不均匀

**问题**: 训练数据的分布与实际运行轨迹的分布存在根本性脱节。

**证据**:
- `generate_training_data()` 在状态空间中均匀随机采样：phi in [-0.5, 0.5], delta in [-0.3, 0.3], phi_dot in [-2.0, 2.0], delta_dot in [-1.0, 1.0], tau in [-50, 50]
- 但 LQR 控制下的实际轨迹只覆盖状态空间的一个极小子流形（manifold）
- 训练数据中 99% 的样本从未在实际 rollout 中出现

**深层影响**:
- 模型在"不可能到达的状态"上浪费了大量容量
- 模型在实际运行轨迹附近的学习精度被稀释
- 这解释了为什么单步精度尚可但多步 rollout 迅速发散 -- 训练数据不覆盖 rollout 轨迹的邻域

**量化估计**:
- 7D 状态空间体积：O(1^7) = O(1)
- LQR 控制下实际可达状态体积：O(0.01^7) = O(10^{-14})
- 覆盖率：约 10^{-14}，几乎为零

**根因级别**: **FUNDAMENTAL** -- 这是数据驱动方法在高维空间中的经典诅咒。

### 1.2 速度范围极窄导致动力学退化

**问题**: 速度范围 [0.54, 0.66] m/s（归一化后），导致自行车动力学的非线性特性几乎不可见。

**物理背景**:
- 自行车的自稳定速度范围：4-6 m/s（Meijaard 基准）
- 当前数据速度约 2 m/s，远低于自稳定速度
- 在低速下，离心力项 v^2/(h*L) 很小（约 0.45），陀螺效应弱
- 动力学退化为近似线性的"倒立摆 + 转向"模式

**深层影响**:
- 模型学到的动力学是退化的线性系统，不是完整的自行车动力学
- 速度条件化（v 作为输入）几乎没有信息量，因为 v 几乎不变
- 泛化到不同速度（如 4 m/s）时性能会急剧下降

**与 e_y/e_psi 困难的关系**:
- e_y_dot = v * sin(e_psi)，当 v 几乎恒定时，e_y 的变化完全由 e_psi 决定
- 但 e_psi 的变化又依赖于 delta 和 v 的耦合
- 在窄速度范围内，这种耦合的多样性不足，模型学不到鲁棒的映射

### 1.3 数据中缺乏"恢复轨迹"

**问题**: 训练数据主要来自 LQR 控制下的平衡轨迹，缺乏大偏差后的恢复过程。

**证据**:
- 初始状态在 [-0.25, 0.25] 均匀采样
- LQR 快速将状态拉回平衡点附近
- 之后的轨迹都在平衡点附近小幅波动
- 模型从未见过"从大偏差恢复"的完整过程

**深层影响**:
- 这正是 e_y 和 e_psi 误差最大的原因 -- 它们的变化模式（从大偏差到零）在训练数据中极为罕见
- 模型只学到了"在平衡点附近小幅振荡"的动力学
- 一旦 rollout 中 e_y 偏离训练分布，模型就无法正确预测恢复过程

### 1.4 数据质量：归一化空间的信息损失

**问题**: 归一化处理虽然有利于训练稳定性，但引入了信息损失。

**具体分析**:
- state_std 对每个维度独立归一化，忽略了维度间的相关性
- 例如 theta 和 theta_dot 有强相关性（一个是另一个的积分），但归一化后这种关系被破坏
- delta_std 的归一化使残差信号被压缩到极小范围（0.3-0.8%），信噪比极低

**AGENT_A 发现的 CRITICAL-2 佐证**:
- 一致性损失 theta_next = theta + theta_dot * dt 在归一化空间中不成立
- 因为 theta/std_theta != theta/std_theta + (theta_dot/std_theta_dot) * dt
- 这说明归一化破坏了物理方程的结构

## 2. 模型层面问题

### 2.1 Neural ODE 架构的根本性不适配

**问题**: Neural ODE 假设系统是自治的（autonomous）或连续时间的，但自行车控制系统本质上是离散的、有控制的、非自治的。

**深层分析**:

**2.1.1 连续时间假设的失效**

Neural ODE 学习 dx/dt = f(x, u)，然后通过积分获得 x(t+dt)。这假设：
- 系统的动力学可以用连续向量场描述
- 积分步长 dt 是任意可选的
- 向量场在 [t, t+dt] 区间内近似恒定

但对于自行车控制系统：
- 控制输入 u 在每个控制周期内是分段常数（采样保持）
- 系统在 dt=1/30s 内的动力学变化可能很显著（转向响应时间常数约 0.1-0.5s）
- 连续时间建模引入了不必要的积分误差

**2.1.2 Euler 积分的结构性偏差**

AGENT_C 分析确认：
- Euler 全局截断误差 O(dt) = O(1/30) ≈ 0.033
- 经过 500 步累积：约 0.033 * 500 = 16.5（未考虑误差传播）
- 实际误差通过 Lyapunov 指数放大

更关键的是：Euler 积分对不同状态维度的影响不同：
- v (慢动态): Euler 误差小
- theta_dot (快动态): Euler 误差大
- 这导致不同维度的预测精度不一致

**2.1.3 缺乏稳定性保证**

Neural ODE 的向量场 f(x, u) 没有任何稳定性约束。如果 f 的 Jacobian 有正实部特征值，轨迹会指数发散。这在自行车系统中特别严重，因为：
- g/h = 12.2625 > 0，意味着横滚角天然不稳定
- 模型必须学到精确的 LQR 控制效果来抵消不稳定性
- 任何微小的模型误差都会被不稳定性放大

### 2.2 GP 核函数的根本性不适配

**问题**: RBF 核假设函数是光滑的、各向同性的，但自行车动力学是各向异性的、有间断的。

**深层分析**:

**2.2.1 RBF 核的各向同性假设**

当前 GP 使用 `ConstantKernel(1.0) * RBF(length_scale=1.0)`：
- 单一 length_scale 假设所有输入维度的尺度相同
- 但状态空间中不同维度的物理意义和变化尺度完全不同
- e_y (米级) vs theta_dot (弧度/秒级) 的变化模式完全不同

**2.2.2 GP 学到的是"保守映射"而非"动力学"**

ROOT_CAUSE_REVEALED.md 揭示的关键发现：
- GP 对 e_y 只预测了真实变化的 5.6%
- GP 对 e_psi 和 theta_dot 直接预测为零
- GP 的"长期稳定"是因为它根本不动（delta near 0）

这不是 GP 的优势，而是它的根本缺陷：
- GP 的先验均值是零，当训练数据中信号稀疏时，后验均值趋向先验
- RBF 核的平滑性假设阻止了 GP 学到突变的动力学行为
- GP 本质上是在做"回归到均值"，而不是"预测动力学"

**2.2.3 GP 的计算复杂度限制**

- sklearn GP 的训练复杂度 O(n^3)，预测复杂度 O(n)
- 5000 样本限制导致信息损失
- 无法处理 150k 样本的完整数据集

### 2.3 模型架构缺乏物理归纳偏置

**问题**: 当前所有模型（Neural ODE, GP, NN）都是纯数据驱动的，缺乏自行车动力学的物理归纳偏置。

**缺失的关键归纳偏置**:

| 物理先验 | 类型 | 当前状态 | 影响 |
|----------|------|----------|------|
| e_y_dot = v * sin(e_psi) | 运动学（精确） | 未嵌入 | e_y 误差累积 |
| e_psi_dot = -v * delta / L | 运动学（精确） | 未嵌入 | e_psi 误差累积 |
| theta_ddot ~ (g/h) * theta | 动力学（近似） | 未嵌入 | 重力项学习困难 |
| 能量守恒 | 物理约束 | 未嵌入 | 长时域能量爆炸 |
| 角度周期性 | 几何约束 | 未嵌入 | 角度表示不连续 |

**AGENT_D 的分析确认**:
- 运动学关系是 100% 精确的，Neural ODE 不需要学习它们
- 但当前模型被迫从数据中重新发现这些关系
- 数据中的噪声和有限性导致这些关系学习不准确

### 2.4 模型容量与问题复杂度的不匹配

**问题**: V9 Neural ODE 仅 9,351 参数，可能不足以捕捉自行车动力学的全部复杂度。

**反面证据**:
- V10/V11 增加容量后效果更差，说明容量不是主要瓶颈
- 但这是因为增加容量的同时没有改善训练策略和数据质量

**更深层的分析**:
- 问题不在于参数数量，而在于参数的有效利用
- 当前模型用 9,351 参数学习 7 个状态的完整动力学
- 如果嵌入物理先验，模型只需学习残差，9,351 参数可能已经足够
- 如果不嵌入物理先验，即使增加到 100,000 参数，也可能因为数据不足而过拟合

## 3. 训练层面问题

### 3.1 多步训练损失完全失效（CRITICAL BUG）

**AGENT_A 发现的核心问题**:

```python
# Line 97: shuffle 破坏了时序连续性
loader = DataLoader(ds, batch_size=config.batch_size, shuffle=True)

# Lines 131-137: 假设 sb[i] 和 sb[i+1] 是时序连续的
s_cur = sb[:n_roll].clone()
for step in range(rollout_steps):
    dsdt = self._model(s_cur, ab[step:step+n_roll])
    s_cur = s_cur + dsdt * self._dt
    target = sb[step+1:step+1+n_roll]  # 随机目标！
    loss_multi += mse(s_cur, target)
```

**深层影响**:
- 占总损失 30% 的多步损失产生的是噪声梯度
- 课程学习（rollout_steps 从 1 到 20）完全浪费
- 模型从未真正学会多步一致性
- 这直接解释了为什么长时域预测差

**为什么这个问题如此致命**:
- 多步损失是训练模型进行长时域预测的唯一机制
- 没有多步损失，模型只学到了单步映射的均值
- 单步均值映射在多步 rollout 中会累积偏差

### 3.2 一致性损失在归一化空间中的维度错误（CRITICAL BUG）

**AGENT_A 发现的第二个核心问题**:

```python
# 归一化空间中的运动学方程不成立
theta_pred = s_next_norm[:, 3]          # theta_next / std_theta
theta_dot = sb[:, 4]                     # theta_dot / std_theta_dot
theta_gt = sb[:, 3] + theta_dot * self._dt  # 错误！
```

正确的关系应该是：
```
theta_next_norm = theta_norm + (theta_dot_norm * std_theta_dot * dt) / std_theta
```

**深层影响**:
- 对 theta 维度施加了错误的梯度方向
- 如果 std_theta 和 std_theta_dot 差异大（通常如此），误差显著
- 破坏了 theta 和 theta_dot 之间的物理一致性

### 3.3 单步训练目标与长时域预测目标的根本性不一致

**问题**: 当前训练优化的是单步预测误差，但评估的是长时域 rollout 误差。这两个目标在数学上是不等价的。

**数学分析**:
- 单步损失：L_1 = E[|f(x, u) - delta_true|^2]
- 多步损失：L_H = E[|x_H - x_H_true|^2]
- 由于 x_H = x_0 + sum_{t=0}^{H-1} f(x_t, u_t)，误差通过求和累积
- 最优的 L_1 不一定是最优的 L_H

**更深层的问题**:
- 即使 L_1 = 0（完美单步预测），如果 f 有系统性偏差，L_H 也会发散
- 这是因为系统是不稳定的（g/h > 0），微小偏差被指数放大
- 需要的是"在 rollout 轨迹上准确"，而不是"在训练分布上平均准确"

### 3.4 缺乏课程学习的正确实现

**问题**: 当前的课程学习（curriculum learning）概念正确但实现失败。

**应有的课程学习**:
1. 阶段 1: 单步预测（H=1），建立基础动力学
2. 阶段 2: 短多步（H=5-10），学习误差修正
3. 阶段 3: 中多步（H=20-50），学习稳定性
4. 阶段 4: 长多步（H=100-500），学习长期一致性

**当前失败原因**:
- 阶段 2-4 的训练数据是随机的（shuffle bug），无法提供有效的梯度信号
- 即使修复 shuffle bug，也需要正确的归一化处理
- 需要从真实轨迹中采样连续段，而不是从随机状态开始

### 3.5 损失函数缺乏物理约束

**问题**: 当前损失函数是纯数据驱动的 MSE，缺乏物理约束项。

**应有的损失函数**:
```
L_total = L_data + lambda_1 * L_kinematics + lambda_2 * L_energy + lambda_3 * L_stability
```

其中：
- L_data: 数据拟合损失（当前已有）
- L_kinematics: 运动学一致性损失（e_y_dot = v*sin(e_psi) 等）
- L_energy: 能量守恒约束（防止长时域能量爆炸）
- L_stability: 稳定性约束（Jacobian 特征值实部 < 0）

**当前状态**:
- L_kinematics: 部分实现但有 bug（CRITICAL-2）
- L_energy: 未实现
- L_stability: 有 Jacobian 正则化但权重太小（lambda=0.01）

## 4. 物理层面问题

### 4.1 自行车动力学的内在不稳定性

**核心物理事实**: 自行车在低速下是开环不稳定的。

**数学表达**:
```
theta_ddot = (g/h) * theta + ...
```

其中 g/h = 12.2625 > 0，意味着：
- 无控制时，横滚角 theta 呈指数增长
- 有 LQR 控制时，theta 被稳定在平衡点附近
- 模型必须精确学到 LQR 的稳定化效果

**对预测模型的影响**:
- 模型误差相当于"控制偏差"
- 不稳定性会放大这个偏差
- 误差增长速率 ≈ exp(lambda_max * t)，其中 lambda_max ≈ sqrt(g/h) ≈ 3.5
- 在 H=500 步（16.7 秒）时，误差放大倍数 ≈ exp(3.5 * 16.7) ≈ 10^{25}

**这是长时域预测困难的根本物理原因。**

### 4.2 未建模的物理效应

**4.2.1 轮胎力学**

当前模型使用线性化的轮胎模型，但实际轮胎有：
- 非线性侧偏刚度
- 轮胎松弛长度（tire relaxation length）
- 纵向-侧向力耦合
- 载荷转移效应

这些效应在大转向角或高速时显著，但在当前数据范围内（低速、小角度）可能被忽略。

**4.2.2 骑手动力学**

当前模型假设骑手是刚性连接的，但实际骑手有：
- 主动平衡控制
- 身体姿态调整
- 质量分布变化

**4.2.3 环境扰动**

当前数据来自理想仿真，缺乏：
- 风扰动
- 路面不平
- 坡度变化

### 4.3 线性化模型与真实动力学的差距

**问题**: 当前使用的线性化模型（path_tracking_env.py）与 Meijaard 基准有显著差异。

**参数对比**:

| 参数 | 线性化模型 | Meijaard 基准 | 差异 |
|------|-----------|---------------|------|
| trail | 0.15 m | 0.069 m | 117% |
| wheelbase | 1.0 m | 1.121 m | 11% |
| 自稳定速度 | 无 | 4-6 m/s | 关键差异 |
| g/h | 12.2625 | ~12.0 | 2% |

**深层影响**:
- trail 差异 117% 导致转向-横滚耦合的强度完全不同
- 线性化模型没有自稳定速度范围，意味着在任何速度下都是不稳定的
- 这导致模型学到的动力学与真实物理不一致

### 4.4 物理约束嵌入的缺失

**AGENT_D 识别的物理先验优先级**:

| 优先级 | 先验 | 类型 | 当前状态 |
|--------|------|------|----------|
| P0 | e_y_dot = v * sin(e_psi) | 运动学（精确） | 未正确嵌入 |
| P1 | e_psi_dot = -v * delta / L | 运动学（精确） | 未嵌入 |
| P2 | theta_dot = d(theta)/dt | 定义 | 有 bug |
| P3 | theta_ddot ~ (g/h) * theta | 动力学 | 未嵌入 |
| P4 | delta_ddot ~ -wn^2 * delta | 动力学 | 未嵌入 |

**为什么物理约束如此重要**:
- P0 和 P1 是精确的几何关系，嵌入后可以完全消除 e_y 和 e_psi 的模型误差
- 当前 e_y 和 e_psi 是误差最大的状态（NMAE 0.72 和 0.89）
- 嵌入这些约束后，模型只需学习 5 个状态的残差动力学，学习负担大幅降低

### 4.5 能量守恒的缺失

**问题**: 自行车系统有耗散力（轮胎摩擦、空气阻力），但没有能量守恒约束。

**影响**:
- 模型可能学到"能量产生"的动力学（物理上不可能）
- 长时域预测中能量可能无限增长，导致发散
- Port-Hamiltonian 框架可以自然地处理这个问题

## 5. 评估层面问题

### 5.1 评估指标不能反映真实性能

**5.1.1 NMAE 的误导性**

NMAE = MAE / state_range，但：
- 对于 v, theta, delta 等变化小的状态，NMAE 可能很小但绝对误差不一定小
- 对于 e_y, e_psi 等变化大的状态，NMAE 很大但可能是"正确方向的误差"
- 不同状态的 NMAE 不可直接比较

**5.1.2 存活率的人为膨胀**

AGENT_A 发现：
- 物理存活限制过于宽松（e_y < 5m, delta < pi/2）
- 一个预测 delta=80 度的模型仍然"存活"，尽管物理上不可能
- 存活率不能反映模型的真实物理合理性

**5.1.3 PrimaryLongHorizonScore 的权重问题**

```
PrimaryLongHorizonScore = mean(NMAE_H100, NMAE_H200, NMAE_H500)
```

- 对 H=100, 200, 500 等权重，但实际应用中不同 horizon 的重要性不同
- 对于 MPC 规划，H=10-50 的精度可能比 H=500 更重要
- 应该根据实际应用需求加权

### 5.2 评估方法存在偏差

**5.2.1 存活轨迹偏差（MEDIUM-1）**

AGENT_A 发现：
- 死亡轨迹只贡献部分（较短）的 NMAE，通常较低
- 报告的 H=500 NMAE 可能被死亡轨迹的低 NMAE 人为拉低
- 应该只计算存活完整 horizon 的轨迹的 NMAE

**5.2.2 评估 segment 的代表性**

- 仅 5 个 segment，seed=42
- 可能不代表整体分布
- 应该增加到 20+ segments，多 seed 评估

**5.2.3 规划验证的自洽性问题**

AGENT_A 发现：
- Phase 3F 的规划评估使用同一个 Neural ODE 作为"真实动力学"
- 测量的是自洽性而非真实性能
- Spearman=1.000, Regret=0.000 是自洽性的完美，不是性能的完美

### 5.3 评估标准不统一

**问题**: 不同方法使用不同的评估协议。

| 方法 | 评估步数 | 初始状态 | 控制策略 |
|------|----------|----------|----------|
| 12种基础方法 | [1,5,10,20,50,100,200,500] | 随机 | LQR |
| V9 Neural ODE | [1,10,50,100,200,500,1000] | 随机 | LQR |
| GP+Ensemble | 500 | 随机 | LQR |

**影响**:
- 不同方法的结果不可直接比较
- 需要统一的评估框架

### 5.4 缺乏统计显著性检验

**问题**: 报告的结果没有置信区间和统计显著性检验。

**AGENT_H 建议**:
- 至少 3 个训练 seed
- 至少 20 个评估 segment
- 报告均值和标准差
- 使用配对 t 检验或 Wilcoxon 检验比较方法

### 5.5 缺乏物理合理性评估

**问题**: 当前评估只关注数值误差，不关注物理合理性。

**应有的评估维度**:
- 能量是否守恒（或合理耗散）
- 角度是否在物理范围内
- 速度是否合理
- 轨迹是否平滑
- 是否满足运动学约束

## 6. 跨维度交互问题

### 6.1 数据-模型交互：分布偏移的正反馈

```
训练数据（均匀采样） → 模型学到"平均"动力学
                        ↓
                   rollout 中状态偏离训练分布
                        ↓
                   模型在 OOD 区域预测不准
                        ↓
                   误差累积，状态进一步偏离
                        ↓
                   指数发散
```

这是 Neural ODE 长时域预测失败的核心机制。

### 6.2 模型-训练交互：无效的多步训练

```
多步损失需要连续轨迹段 → DataLoader shuffle 破坏连续性
                          ↓
                     多步损失变成噪声
                          ↓
                     模型只学好单步
                          ↓
                     多步 rollout 误差累积
```

### 6.3 物理-评估交互：不稳定性放大评估误差

```
物理不稳定性 (g/h > 0) → 模型误差被指数放大
                          ↓
                     长时域 NMAE 快速增长
                          ↓
                     评估指标恶化
                          ↓
                     但评估指标不区分"模型误差"和"物理不稳定性放大"
```

### 6.4 数据-物理交互：窄速度范围掩盖非线性

```
速度范围窄 [0.54, 0.66] → 动力学退化为近线性
                           ↓
                      模型学到线性近似
                           ↓
                      泛化到不同速度时失败
                           ↓
                      无法处理完整的自行车动力学
```

## 8. 综合修复方案

### 8.1 Phase 0: 紧急 Bug 修复（1 天）

1. **修复 shuffle bug**: 使用 SequentialSegmentDataset，确保多步训练使用连续轨迹段
2. **修复归一化一致性损失**: 在物理空间中计算一致性损失
3. **收紧物理存活限制**: delta < pi/4, e_y < 2.0m

### 8.2 Phase 1: 物理约束嵌入（2-3 天）

1. **硬编码运动学**: e_y_dot = v*sin(e_psi), e_psi_dot = -v*delta/L
2. **UDE 风格物理-残差分离**: 已知物理项 + NN 残差
3. **能量守恒约束**: 防止长时域能量爆炸

### 8.3 Phase 2: 训练策略改进（3-5 天）

1. **正确的课程学习**: 1 → 5 → 10 → 20 → 50 → 100 → 200 步
2. **多步损失修复后重新训练**: 使用连续轨迹段
3. **Scheduled sampling**: 逐渐从 teacher forcing 过渡到自由运行

### 8.4 Phase 3: 数据增强（2-3 天）

1. **扩大速度范围**: 采集 v = 2-6 m/s 的数据
2. **增加恢复轨迹**: 从大偏差初始状态采集
3. **增加工况多样性**: 直线、弯道、紧急转向

### 8.5 Phase 4: 模型架构升级（5-7 天）

1. **Deep Koopman**: 在 lifted 空间中用线性算子预测
2. **Port-Hamiltonian NN**: 嵌入能量守恒结构
3. **Switching LDS**: 多 regime 线性模型

### 8.6 Phase 5: 评估框架统一（1-2 天）

1. **统一评估协议**: 固定评估 segment、seed、horizon
2. **添加统计检验**: 置信区间、显著性检验
3. **添加物理合理性指标**: 能量、角度范围、平滑性

## 9. 核心洞察总结

### 9.1 为什么 e_y 和 e_psi 预测困难？

**表面原因**: 动态大，变化快。
**深层原因**:
1. 运动学关系 e_y_dot = v*sin(e_psi) 没有被硬编码，模型被迫从数据中学习
2. 训练数据中缺乏"从大偏差恢复"的轨迹，模型没见过 e_y 和 e_psi 的完整变化模式
3. 物理不稳定性 (g/h > 0) 放大了 e_y 和 e_psi 的预测误差
4. 多步训练损失失效，模型从未学会多步一致性

### 9.2 为什么 v, theta, delta 预测容易？

**表面原因**: 动态小，变化量接近零。
**深层原因**:
1. 这些状态在 LQR 控制下变化很小，预测"不变"就是很好的近似
2. GP 学到的"delta near 0"对这些状态恰好是正确的
3. 这些状态的物理约束较强（速度恢复、角度范围限制）

### 9.3 为什么长时域预测误差累积？

**表面原因**: 误差线性/指数累积。
**深层原因**:
1. 物理不稳定性 (g/h > 0) 导致误差指数放大
2. 多步训练损失失效，模型从未学会控制误差累积
3. 分布偏移导致 OOD 区域的预测不准
4. Euler 积分误差在长时间内累积

### 9.4 为什么 GP "成功"但实际失败？

**表面原因**: GP 长期稳定（MAE=0.15）。
**深层原因**:
1. GP 学到的是"近恒等映射"（delta near 0），不是真正的动力学
2. GP 的长期稳定是因为它根本不动，不是因为预测准确
3. GP 的 RBF 核平滑性阻止了它学到突变的动力学行为
4. GP 的"成功"是一种"保守到极点"的策略

### 9.5 为什么 NN 残差全部失败？

**表面原因**: 残差太小，信噪比低。
**深层原因**:
1. 残差仅占总变化的 0.3-0.8%，NN 很难学到有意义的模式
2. 符号一致率仅 78.9%，21% 的修正是反方向的
3. 分布偏移导致 NN 在 OOD 区域输出错误残差
4. 正反馈放大误差：错误残差 → 状态偏移 → 更大错误残差

---

## 10. 结论

本项目的根本问题不是某个单一因素，而是多个因素的系统性交互：

1. **数据问题**: 训练数据不覆盖实际运行轨迹，速度范围窄，缺乏恢复轨迹
2. **模型问题**: 缺乏物理归纳偏置，连续时间假设不适配，GP 核函数不适配
3. **训练问题**: 多步损失失效（bug），归一化破坏物理结构，损失函数缺乏物理约束
4. **物理问题**: 内在不稳定性未被约束，运动学关系未被嵌入
5. **评估问题**: 指标不完善，方法不统一，缺乏统计检验

**最关键的修复**:
1. 修复 shuffle bug（立即）
2. 嵌入运动学硬编码（高优先级）
3. 实现 UDE 风格物理-残差分离（中优先级）
4. 扩展数据覆盖度（中优先级）
5. 统一评估框架（持续）

**最终目标**: 构建一个既能学到真正动力学，又能控制误差累积的模型。这需要同时解决数据、模型、训练、物理、评估五个层面的问题。
