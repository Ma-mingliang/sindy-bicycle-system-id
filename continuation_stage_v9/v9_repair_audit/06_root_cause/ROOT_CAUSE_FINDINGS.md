# 根因发现综合报告（14.1-14.4）

## 14.1 确认的根因

### 根因 #1: shuffle=True 破坏多步损失时间顺序
- **严重度**: CRITICAL
- **证据来源**: Agent A, B, C, D 四方独立确认
- **代码位置**: `neural_ode_v9.py` L96-97 (DataLoader), L133-137 (rollout)
- **机制**: `DataLoader(shuffle=True)` 打乱单个时间步。多步 rollout 假设 `sb[i+1]` 是 `sb[i]` 的时间后继，实际是随机配对。损失变为梯度噪声。
- **修复状态**: V12 已修复（SequentialSegmentDataset）

### 根因 #2: 多步 Rollout 归一化空间不匹配
- **严重度**: CRITICAL
- **证据来源**: Agent B (数学证明), Agent C (数值推导), Agent D (训练异常归因)
- **代码位置**: `neural_ode_v9.py` L92 (目标构建), L135 (rollout 更新)
- **机制**:
  - 训练目标: `deltas / (delta_std * dt)` — 归一化空间 A
  - Rollout 更新: `s_cur + dsdt * dt` = `s/state_std + deltas/delta_std` — 归一化空间 B
  - 目标值: `s_next/state_std` = `s/state_std + deltas/state_std` — 归一化空间 C
  - 除非 `delta_std == state_std`，否则 A≠B≠C
- **修复状态**: V12 已修复（统一使用 `deltas / state_std`）

### 根因 #3: 训练 Rollout 上限 (20) vs 评估 (500+)
- **严重度**: CRITICAL
- **证据来源**: Agent A (配置分析), Agent D (因果图)
- **代码位置**: `config_v9.py` L24 (`rollout_curriculum = '1,5,10,20'`)
- **机制**: 最大训练 rollout 20 步，评估需要外推 25 倍到 H=500
- **修复状态**: V12 部分修复（扩展到 '1,5,10,20,50,100'）

### 根因 #4: 一致性损失归一化错误
- **严重度**: MEDIUM
- **证据来源**: Agent A, B, C 三方确认
- **代码位置**: `neural_ode_v9.py` L143-148
- **机制**: `theta_gt = sb[:,3] + sb[:,4] * dt` 缺少 `state_std[4]/state_std[3]` 修正因子
- **修复状态**: V12 已修复（`_std_ratio`）

## 14.3 根因交互分析

| 根因组合 | 效果 | 解释 |
|----------|------|------|
| #1 alone (shuffle 修复) | H=500 NMAE=0.476, 0% 存活 | 模型学到动力学但发散 |
| #1 + #2 (归一化也修复) | 效果与 #1 alone 相似 | 归一化差异在 V9 中部分抵消 |
| #1 + 收缩性 | H=500 NMAE=0.958, 100% 存活 | 精度-稳定性权衡 |
| #1 + #3 (扩展课程) | 未测试 | 可能进一步改善中 horizon |

**关键发现**: 根因 #1 (shuffle) 是必要但不充分条件。修复后暴露了更深层的精度-稳定性权衡。
